1. Ax = b 几何与列视角

每个方程是一张平面（二维里是直线）。解 = 所有平面交在一起的地方：一个交点 / 平行无交 / 重合无穷多。
行视角：平面相交情况

列视角（更基本）

把 A 的每一列看成一根积木。Ax = b 在问：能不能用这些积木（按 x 的系数）拼出 b？
  • 拼得出 → b 在列空间里 → 有解
  • 拼不出 → 在列空间里找离 b 最近的点 → 最小二乘
列空间外的 b → 投影（注意：两无关平面向量会张成整个平面，演示「在外」需列空间是真子空间）

2. 高斯消元与部分主元

解方程组像整理式子：用一行减另一行的倍数，消掉下面的未知数，变成「楼梯形」上三角，再从最底下的未知数往回解。
对每列 k：选主元（下方最大）→ 换行 → 用倍数把下方消成 0
得到 Ux = c 后回代
主元太小会放大浮点误差。部分主元：每次选列中最大元当主元。

3. LU · QR · Cholesky

LU：A = LU

消元时的「倍数」存进 L，消完的上三角是 U。同一 A、很多个 b 时：分解一次 O(n³)，之后每个 b 只需 O(n²) 前代+回代。
Ly = b（前代）→ Ux = y（回代）

QR：A = QR

用 Gram-Schmidt 把列变成互相垂直的单位向量（Q），投影长度放进 R。
q₁ = a₁/‖a₁‖
v₂ = a₂ − (a₂·q₁)q₁ → q₂ = v₂/‖v₂‖
解：Rx = Qᵀb 再回代（最小二乘常更稳）
Gram-Schmidt：减投影 → 残差方向单位化

Cholesky：A = LLᵀ

A 对称正定（协方差、XᵀX+λI）时可用。只算一半，大约比 LU 快一倍。
Lᵢᵢ = √(Aᵢᵢ − Σ Lᵢₖ²)
Lᵢⱼ = (Aᵢⱼ − Σ Lᵢₖ Lⱼₖ) / Lⱼⱼ

4. 最小二乘与正规方程

数据点比参数多：没有一条直线穿过所有点。改为：找让「竖直误差平方和」最小的直线。
正规方程不是新算法，而是「损失最低」的条件：
拧截距、斜率两个旋钮，平方误差 L 到谷底时，对两个旋钮的变化率都是 0 → 整理成 AᵀA w = Aᵀb。
最小化 ‖Aw − b‖²
⇒ Aᵀ A w = Aᵀ b
回归：XᵀX w = Xᵀy　（同一件事）
线性回归 = 正规方程的几何图像
岭回归：(XᵀX + λI)w = Xᵀy，λ>0 时可用 Cholesky，并改善条件数。

5. 伪逆 A⁺（Moore-Penrose）

普通逆只服务「方阵且可逆」。伪逆是备用方案：三种尴尬局面各给一个「最合理」答案。
局面伪逆给出
无精确解（超定）最小二乘解（残差最短）
无穷多解（欠定）其中 ‖x‖ 最小的
唯一解与 A⁻¹b 相同
A = UΣVᵀ → A⁺ = V Σ⁺ Uᵀ（非零奇异值取倒数）
三幕剧记忆法

6. 条件数 κ

软尺子：手抖一下读数大变；硬尺子：几乎不变。条件数描述「从 b 反推 x」有多娇气。
κ(A) = σ_max / σ_min
  • κ ~ 1–100：较安全
  • κ ~ 10ᵏ：大约丢 k 位有效数字
  • κ ~ 10¹⁶：解基本没意义
特征共线、尺度混乱 → κ 变大。正则化、标准化、改用 QR/SVD 可缓解。

7. 共轭梯度（CG）

百万维稀疏系统：LU/Cholesky 分解不动。改为从一个猜测出发，一步步走，只反复做「稀疏矩阵×向量」。

要求 A 对称正定。精确算术下最多 n 步；条件数小则通常更快。用于大规模牛顿法、PDE、大核矩阵等。

8. 方法怎么选 · ML 联系

方法何时用
高斯消元中小方阵，解一次
LU同一 A、多个 b
QR最小二乘，要稳
Cholesky对称正定（协方差、岭回归）
正规方程回归闭式，n 不大
SVD/伪逆秩亏、统一最小二乘/最小范数
CG大稀疏对称正定
  • 线性/岭回归 → 正规方程或 QR/Cholesky
  • 高斯过程 → Cholesky 解 Kα=y，并算 log det
  • 正交初始化 → QR
  • 特征共线 → 看条件数，丢特征或加 λ

9. 一句话速查

  • 列视角 b 能否由列拼成；否则投影
  • 消元 变上三角 + 回代；要主元
  • LU 倍数→L，结果→U；多次求解
  • QR 列正交化；最小二乘稳
  • Cholesky A=LLᵀ；对称正定
  • 正规方程 损失谷底 = AᵀAw=Aᵀb = 线性回归
  • 伪逆 无解→LS；多解→最短；可逆→普通逆
  • 条件数 解对噪声有多敏感
  • CG 大稀疏 SPD 迭代解
复习口诀：先问有没有精确解（列空间）→ 没有就投影/最小二乘 → 用分解或伪逆算出来 → 用条件数判断信不信 → 矩阵太大就迭代。
