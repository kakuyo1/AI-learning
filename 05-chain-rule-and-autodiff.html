05 Chain Rule & Automatic Differentiation

高可视化复习 · 链式法则 · 计算图 · 前向/反向模式 · 对偶数 · PyTorch Autograd

1. 链式法则（The Chain Rule）

复合函数的导数 = 各层局部导数相乘。
y = f( g(x) )
dy/dx = f'(g(x)) · g'(x)

神经网络是函数套函数，反向传播就是反复使用链式法则。

一层套一层时，导数如何传递
x
→
g(x)
→
f(g)
→
y

反向时：从 y 把梯度一路乘回来

dy/dx
←
× g'(x)
←
× f'(g)
←
dy/dy=1

2. 计算图（Computational Graph）

每个操作变成一个节点。数据向前流，梯度向后流。

Forward pass（前向：算值）

x1=2, x2=3 → 相乘 → 加 b=1 → ReLU → y

Backward pass（反向：算梯度）

从 dy/dy=1 开始，一路把梯度传回去

每一步：当前梯度 = 后面传来的梯度 × 本层局部导数

Forward = 从输入算到损失（算值）  |   Backward = 从损失倒着走，算每个参数的梯度（算责任）

3. Forward Mode vs Reverse Mode

模式 种子 方向 最适合的场景
Forward Mode
前向模式		 dx/dx = 1 输入 → 输出 输入少、输出多
Reverse Mode
反向模式		 dy/dy = 1 输出 → 输入 输入多、输出少（神经网络）
神经网络：权重几百万（输入多），损失只有 1 个（输出少）→ 必须用反向模式，一次算出所有梯度。

4. Dual Numbers（对偶数）——前向模式的优雅实现

对偶数 = 把「值」和「导数」绑在一起的数字：a + b·ε（规定 ε² = 0）
(a, a') + (b, b') = (a+b, a'+b')
(a, a') × (b, b') = (a×b, a'×b + a×b')
sin(a, a') = (sin(a), cos(a)×a')

你按普通算术计算，导数会自动跟着走完整个前向过程。

点击查看完整小例子：y = sin(x²)，x=2
1. x = (2, 1)　　　　　　　// 值=2，导数=1
2. a = x² = (2,1)×(2,1) = (4, 4)
3. y = sin(a) = (sin4, cos4×4) ≈ (−0.757, −2.615)

一次计算同时得到函数值和导数。

5. How PyTorch Autograd Works Under the Hood

你写的代码 vs PyTorch 内部自动做的事

内部计算图长这样

y = x² + 3x + 1 对应的计算图
点击查看 backward() 时梯度如何一步步传回
  1. 给 y 的梯度设为 1.0
  2. 经过「+1」→ 梯度 1 传给 (x² + 3x)
  3. 经过「+」→ 梯度 1 分别传给 x² 和 3x
  4. x² 节点：局部导数 2x=4 → 传给 x 的梯度 += 4
  5. 3x 节点：局部导数 3 → 传给 x 的梯度 += 3
  6. 最终 x.grad = 4 + 3 = 7
关键细节：
  • 动态图（Define-by-Run）：每次前向都重新建图，支持 if/for
  • 梯度默认累加（+=），所以要先 zero_grad()
  • 只有 requires_grad=True 的叶子节点会保留梯度

6. 迷你 Autograd 引擎的核心思想

课程要求你手写一个 Value 类，它需要三样东西：

1包装数值
2记录计算图
3反向传播
组件 作用
Value 对象 存 data（值）和 grad（梯度）
_prev 记录自己由哪些节点算出来
_backward 函数 知道如何把上游梯度分给自己的输入
backward() 拓扑排序后倒序执行每个节点的 _backward
# 加法的反向示例
def _backward():
  self.grad += out.grad    # 加法对输入的局部导数是 1
  other.grad += out.grad
这就是 PyTorch autograd 的微型版本。理解它，就理解了所有现代深度学习框架最核心的部分。

7. 一句话速查

  • 链式法则 复合函数导数 = 各层局部导数相乘
  • 计算图 操作变节点，前向算值，反向算梯度
  • Forward Mode 从输入往输出推导数（适合输入少）
  • Reverse Mode 从输出往输入拉梯度（神经网络标配）
  • 对偶数 值+导数绑在一起，前向模式的优雅实现
  • PyTorch Autograd 前向建图 + 记录反向函数，.backward() 自动传梯度
  • Value 类 手写 autograd 的核心：存值、记图、定义局部反向
最终记住：反向传播 = 在计算图上系统地应用链式法则。框架帮你自动完成，但原理就是「从损失倒着乘回来」。
