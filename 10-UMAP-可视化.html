UMAP 可视化直觉

更快、全局结构更好的邻居保持降维

UMAP = 把高维数据看成流形上的一张图，然后在低维重现这张图的连接关系。
比 t-SNE 更快，簇间相对位置通常更有参考价值。

1. 高维：先建一张「邻居图」

UMAP 认为数据躺在低维弯曲流形上。对每个点找近邻，连成加权图：近的边粗（权重大），远的边细。

高维流形上的局部邻居图（示意）

2. 低维：重现相似的连接关系

在 2D 里也放点、连边，调整位置让两张图尽量一致。原来的局部连接被保住，同时全局排布通常比 t-SNE 更合理。

低维结果：局部簇紧凑，簇间相对位置更有意义

3. 两个关键参数

参数 作用 调大时 调小时
n_neighbors 每个点看多少邻居 更重视全局结构 更重视局部，簇更分离
min_dist 低维点允许靠多近 点更分散，结构更松 簇更紧密

4. UMAP vs t-SNE vs PCA

PCA t-SNE UMAP
类型 线性 非线性 非线性
速度 很快 慢 较快
保什么 全局方差 局部邻居 局部 + 更好的全局
簇间距离 有一定意义 基本不可信 相对更可信
主要用途 预处理 / 压缩 好看的 2D 图 可视化（大数据更合适）
实用建议：
· 数据量大、想看结构 → 优先 UMAP
· 只想要最强局部簇分离、数据量小 → t-SNE 仍很强
· 给模型做特征降维 → 仍优先 PCA（或自编码器）
UMAP 和 t-SNE 一样有随机性，多次运行结果不会完全相同；也不要把 2D 坐标直接当模型输入特征（除非经过验证）。

5. 一句话总结

UMAP 用「流形 + 邻居图」的方式做降维，速度更快，全局结构通常好于 t-SNE，是目前高维数据可视化的常用首选。
