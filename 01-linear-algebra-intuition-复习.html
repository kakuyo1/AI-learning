1. Embedding Space（嵌入空间）

一句话：把抽象的“含义”变成可以计算距离和方向的高维数字空间。

一个词 → 一个 768 维（或更高）的向量
意思相近的词，在空间里的距离更近。

词嵌入矩阵

矩阵的每一行对应一个词的向量。查词 = 取出对应的那一行。

真实模型中，单个维度通常没有清晰的人类可解释含义，整个向量才代表语义。

2. Dot Product（点积）

a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ = |a| |b| cosθ

几何意义：衡量两个向量的同向程度。

点积结果含义
> 0方向大致相同（夹角 < 90°）
= 0互相垂直
< 0方向大致相反（夹角 > 90°）

点积 vs 叉积

点积 Dot Product叉积 Cross Product
结果标量（一个数字）3D 是向量，2D 是标量
主要用途同向程度、投影、判断垂直垂直方向、面积、旋转方向
本课是否使用核心工具几乎不涉及

在 AI 中的直接应用

  • Attention 分数：Query · Key，决定关注哪些词
  • 余弦相似度：在 RAG、检索、推荐中衡量两个向量有多像
  • 投影计算：投影公式的核心就是点积
余弦相似度 = (a · b) / (|a| |b|)
它只看方向，忽略长度，是衡量语义相似度的常用指标。

3. 矩阵 = 模型本身

矩阵是一种变换规则：输入一个向量，输出另一个向量（可旋转、缩放、投影）。

在 AI 中的角色具体含义
神经网络权重每一层：输出 = 权重矩阵 × 输入向量
Attention 分数决定当前词该关注哪些其他词
Embeddings词 → 向量的映射矩阵
output = weights @ input_vector # 这就是神经网络一层在做的事情

4. 为什么是 768 / 1024 / 4096 维？

原因

  • 架构约束：总维度 = 注意力头数 × 每个头的维度（常取 64）
  • 768 = 12 头 × 64；1024 = 16 头 × 64
  • 方便 GPU Tensor Core 高效计算

维度大小的影响

维度 ↑维度 ↓
表达能力更强，能区分更细微语义 表达能力有限
存储、计算、检索成本线性增加 更快、更省资源
收益递减（768→4096 提升越来越小） 太小会明显掉点

5. Linear Independence（线性无关）

一组向量线性无关 ⇔ 其中任何一个都不能由其他向量通过加减和倍数运算得到。
v1 = [1, 0, 0] v2 = [0, 1, 0] v3 = [2, 1, 0] # v3 = 2*v1 + v2 → 线性相关

三个向量都在 xy 平面上，无法到达 [0,0,1]。看起来有 3 个，实际自由度只有 2。

对 AI 的意义

  • 特征矩阵的列应尽量线性无关
  • 若特征高度相关（多重共线性）→ 权重不稳定、解不唯一
  • 冗余特征不带来新信息

6. Basis（基）与 Rank（秩）

基（Basis）

一组最小且完整的线性无关向量，能张成整个空间。基的数量 = 空间的维度。

3D 标准基：{[1,0,0], [0,1,0], [0,0,1]}。任何 3 个线性无关的 3D 向量都可做基（换坐标系）。

秩（Rank）

矩阵的秩 = 线性无关列（或行）的最大数量 = 真正提供的独立方向数。

情况含义对 ML 的影响
满秩秩达到最大有唯一稳定解，模型条件良好
秩不足秩 < min(行,列)特征冗余，无穷多解，需正则化
秩为 1所有列共线数据挤在一条线上，表达极弱
接近秩不足有很小的奇异值病态矩阵，输入噪声会被放大

7. Projection（投影）

proj_b(a) = (a · b / b · b) * b

这里的 * 是标量乘向量（数字 × 向量），不是向量乘法。

  • a · b 和 b · b 都是点积，结果是数字
  • 相除得到投影系数（标量）
  • 再乘以向量 b，得到投影结果
残差 = a − proj_b(a)，它与 b 垂直（点积为 0）。
任何向量都可分解为：顺着 b 的部分 + 垂直于 b 的部分。

例子

a = [3, 4], b = [1, 0] proj = (3/1) * [1, 0] = [3, 0] 残差 = [0, 4] （完全垂直）

在 AI 中的位置

  • 线性回归：把观测值投影到特征张成的空间（最小二乘本质）
  • PCA：投影到方差最大的方向
  • Attention：Query 投影到 Key 上计算相似度

8. Gram-Schmidt 过程

目标：把任意线性无关向量变成标准正交基（互相垂直 + 长度都为 1）。

本质：不断计算并保留每个新向量相对于已有正交向量的 residual，再单位化。
u1 = v1 / |v1| w2 = v2 − (v2 · u1) * u1 u2 = w2 / |w2| w3 = v3 − (v3 · u1)*u1 − (v3 · u2)*u2 u3 = w3 / |w3|

几何意义

  1. 第一个向量直接单位化
  2. 后续向量：减去在已有 u 上的所有投影 → 只留纯 residual → 再单位化

维度限制

正交向量个数最少需要维度可视化
22D容易
33D可以
4+4D+无法直接可视化

在 n 维空间最多只能有 n 个两两正交的向量。超出部分正交化后 residual 会变成零（线性相关被检测出来）。

与 QR 分解

Q = 标准正交矩阵，R = 投影系数构成的上三角矩阵。用于稳定求解线性方程组、特征值、最小二乘。

LoRA 特别说明

大模型微调时，不更新完整的巨大权重矩阵（如 4096×4096），而是用两个小的低秩矩阵（4096×16 和 16×4096）近似。

假设有效更新只发生在低维子空间 → 这就是「秩」在工业界的直接应用。
