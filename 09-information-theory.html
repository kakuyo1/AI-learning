09 Information Theory

高可视化复习 · 信息量 · 熵 · 交叉熵 · KL 散度 · 互信息 · 困惑度

0. 先搞清楚：信息论和概率统计是什么关系？

信息论不是全新的数学，而是把概率统计换了一身「不确定性 / 意外程度」的衣服。

你在 06 课学的概率，关注的是「事情发生的可能性是多少」。 信息论在同一套概率之上，多问了一句：

「这件事发生时，有多让人意外？消除了多少不确定？」

概率语言 信息论语言
概率 p(x) 信息量 −log p(x)（有多意外）
一个分布 熵（平均有多不确定）
用模型分布近似真实分布 交叉熵 / KL 散度
两个变量的依赖程度 互信息、条件熵、联合熵
06 课你已经会用交叉熵当损失函数。
09 课是从信息论角度回答：为什么是它？它和熵、KL、困惑度是同一家族的概念。

1. 信息量（Surprise）

越不可能发生的事，发生时越让人惊讶，信息量越大。

I(x) = −log p(x)
  • 概率接近 1 → 信息量接近 0（不意外）
  • 概率接近 0 → 信息量很大（很意外）
  • log2 → 单位是 bit；自然对数 → 单位是 nat（深度学习常用）

2. Entropy（熵）——平均有多让人意外

熵 = 一个分布里所有可能结果的「意外程度」的加权平均。
H(P) = − Σ p(x) · log p(x)
分布特点 熵 含义
结果很平均、很不确定 高 很难猜中
结果很集中、很确定 低 基本已经知道会发生什么
只有一个结果概率为 1 0 完全没有不确定性

例子：公平硬币熵 = 1 bit；99% 正面的硬币熵 ≈ 0.08 bit。

3. Cross-Entropy（交叉熵）——用你的预测理解真实情况时有多意外

交叉熵衡量：真实事件按 P 发生，你却用 Q 的概率去衡量它们时，平均有多惊讶。
H(P, Q) = − Σ p(x) · log q(x)

在分类里，P 是 one-hot，公式简化为你已经熟悉的形式：

H(P, Q) = −log(q(正确类别))

这就是分类任务天天用的交叉熵损失。

和熵的关系：
交叉熵 H(P,Q) = 熵 H(P) + KL散度 D_KL(P || Q)
训练时 H(P) 固定，所以最小化交叉熵 ≡ 最小化 KL 散度 ≡ 让模型分布靠近真实分布。

4. KL Divergence（KL 散度）

KL 散度 = 用预测分布 Q 近似真实分布 P 时，多出的「额外惊讶」。
D_KL(P || Q) = Σ p(x) · log(p(x)/q(x)) = H(P,Q) − H(P)
  • Q 和 P 完全一样 → KL = 0
  • 差得越多 → KL 越大
  • 不对称：D_KL(P||Q) ≠ D_KL(Q||P)，所以不是真正的距离

出现在：VAE、知识蒸馏、RLHF 等需要「让一个分布靠近另一个分布」的地方。

5. Mutual Information / Conditional Entropy / Joint Entropy

这三个概念本质上是概率里「依赖关系」的信息论说法。

概念 一句话 公式直觉
联合熵 H(X,Y) 两个变量合在一起总共有多不确定 H(X,Y) ≤ H(X)+H(Y)
条件熵 H(Y|X) 知道 X 之后，Y 还剩多少不确定 0 ≤ H(Y|X) ≤ H(Y)
互信息 I(X;Y) 知道其中一个，能减少另一个多少不确定 I(X;Y) = H(Y) − H(Y|X)
I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y)
  • X、Y 独立 → 互信息 = 0
  • X 完全决定 Y → 条件熵 = 0，互信息 = H(Y)
  • 互信息是对称的（和 KL 不同）
在特征选择里：互信息高的特征对预测目标更有用（能抓住任意依赖关系，不只是线性相关）。

6. Label Smoothing（标签平滑）

普通交叉熵用硬标签 [0,0,1,0]，模型会过度自信。标签平滑把硬标签稍微打散：

soft = (1−ε)×hard + ε/类别数

例如 ε=0.1、4 类、真实是第 3 类：

硬标签 [0, 0, 1, 0] → 软标签 [0.025, 0.025, 0.925, 0.025]

效果：防止 logits 极端、起到正则化、改善概率校准。

7. 为什么交叉熵是分类的默认损失？

视角 理由
信息论 衡量用模型分布编码真实分布时浪费了多少信息，最小化它让两者对齐
最大似然 交叉熵 = 负对数似然，最小化它 = 最大化数据在模型下的概率
优化 配合 Softmax 后梯度是「预测 − 真实」，形式干净、稳定、好算

三个方向都指向同一个自然选择，所以它成为事实标准。

8. Perplexity（困惑度）

困惑度 = 交叉熵的指数，表示模型平均在多少个选项里均匀犹豫。
Perplexity = e^(交叉熵)　或　2^(交叉熵)
  • 困惑度 = 1 → 完全确定
  • 困惑度 = 50 → 相当于在 50 个词里随机猜
  • 语言模型里越低越好

9. 一句话速查

  • 信息论与概率 同一套数学，换了「意外/不确定性」的视角
  • 信息量 −log p，有多让人意外
  • 熵 一个分布平均有多不确定
  • 交叉熵 用预测理解真实时平均有多意外（分类损失）
  • KL 散度 两个分布差了多少额外意外
  • 互信息 知道一个能减少另一个多少不确定
  • 条件熵 知道 X 后 Y 还剩多少不确定
  • 联合熵 两个变量合在一起总共有多不确定
  • Label Smoothing 软化硬标签，防止过度自信
  • 困惑度 交叉熵的指数，等效犹豫的选项数
最终记住：信息论用「有多意外」重新描述了概率里的不确定性。交叉熵损失、KL 散度、困惑度都是这套语言在机器学习中的直接应用。
