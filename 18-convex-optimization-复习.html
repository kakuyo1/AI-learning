1. 凸集与凸函数

凸集：任意两点的连线都还在集合里（圆盘、矩形行；月牙、甜甜圈不行）。 凸函数：任意两点的弦在图像上方——形状像一只朝上的碗。
f(tx+(1−t)y) ≤ t·f(x)+(1−t)·f(y)　∀ t∈[0,1]
弦测试：凸 vs 非凸

检验：一维 \(f''\ge0\)；多维 Hessian 半正定（特征值 ≥0）。

常见凸函数：\(x^2\)、\(|x|\)、\(e^x\)、\(-\log x\)、线性函数、ReLU（分段线性凸）。

2. 为何凸重要 · ML 里谁凸

中心定理：凸函数的任意局部最小 = 全局最小。梯度下降不会掉进「假谷底」。
问题凸？
线性/逻辑回归、SVM、岭回归、LASSO是
深度网络、k-means、矩阵分解否
线性模型 + 凸损失 → 凸；一加非线性隐层，凸性通常就破了。

3. Hessian 与牛顿法

梯度只告诉「往哪下坡」；Hessian 告诉「坡弯得有多急」。牛顿法在当前点贴一个局部抛物面，一步跳到抛物面最低点。
梯度下降：x ← x − η ∇f
牛顿法：　x ← x − H⁻¹ ∇f
牛顿：跳到局部碗底（二次时一步精确）
  • 优点：近最优二次收敛；少调学习率
  • 缺点：H 内存 O(n²)、求逆 O(n³) → 大网络不可用

4. 约束优化 · 拉格朗日 · KKT

无约束：满世界找最低。有约束：只能在「允许区域」里找——预算、范数上限、概率约束等。

拉格朗日（等式约束）

L = f(x) + λ g(x)
∇f + λ ∇g = 0，且 g=0　→　梯度平行，等高线与约束相切
圆=目标等高线 · 直线=约束 · 相切处 ∇f∥∇g

KKT（不等式约束）

条件含义
平稳性∇f 被有效约束的法向组合顶住
原可行gᵢ(x)≤0
对偶可行λᵢ≥0
互补松弛λᵢ·gᵢ=0：要么贴边，要么 λ=0
SVM 支持向量 = λ>0 的样本，正是互补松弛。

5. 正则化 = 约束优化

「权重要小」写成 ‖w‖≤t，再变成损失里的惩罚项。不是玄学加项，是约束优化的等价形式。
等高线第一次碰到约束边界 = 正则化最优
  • L2 / 岭回归：球约束 → 权重变小，很少精确为 0
  • L1 / LASSO：菱形约束 → 易在角上 → 特征选择

6. 对偶 Duality

每个约束问题（原问题）可配一个乘子上的最大化问题（对偶）。凸时两边最优值常相等（强对偶）。
原：min f s.t. g≤0
L = f + λg　→　d(λ)=min_x L　→　对偶：max d(λ) λ≥0
  • 对偶最优 ≤ 原最优（弱对偶，总成立）→ 下界
  • 凸 + 合适条件 → 相等（强对偶）
  • SVM：对偶只依赖 xᵢ·xⱼ → 换成核 K(xᵢ,xⱼ) 即核技巧

7. 非凸深度网络为何还能工作

按经典理论非凸应很难训，但 SGD 经常能找到好解。课里几个关键点：
  • 坏局部最小很少：高维里临界点几乎都是鞍点，真局部最小损失往往也不差
  • 鞍点才是障碍：SGD 噪声有助于逃离
  • 过参数化：参数多于样本时，损失面更连通、更光滑
  • 随机噪声 ≈ 隐式正则：小 batch 的梯度抖动偏向宽而平的区域，抑制又尖又过拟合的解
不要幻想找到「全局最小」；够好的局部解 + 验证集，才是深度学习的日常。

8. 实践中的二阶方法

完整牛顿要存 H、解线性系，大模型做不到。实践用近似：
方法思路适用
L-BFGS用最近 m 步梯度差近似 H⁻¹中小凸问题
Hessian-free只算 Hv，CG 解牛顿方程较大规模
K-FACFisher 的 Kronecker 近似研究 / 大 batch
Adam 等对角二阶矩（很粗的曲率）深度学习默认

9. 一句话速查

  • 凸函数 弦在上；局部最小=全局最小
  • Hessian 曲率；半正定 → 凸
  • 牛顿 x−H⁻¹∇f；小凸问题快，大网络贵
  • 拉格朗日 等式约束；∇f∥∇g
  • KKT 不等式；互补松弛 → SVM 支持向量
  • L2/L1 球→收缩；菱形→稀疏
  • 对偶 乘子上的 max；SVM 核技巧
  • SGD 噪声 隐式正则，偏平坦解
  • L-BFGS 实用二阶近似，非深度默认
复习口诀：先问凸不凸 → 凸则有保证、可用牛顿/L-BFGS → 有约束用拉格朗日/KKT → 正则是范数约束 → 对偶给 SVM 核技巧 → 深度非凸靠过参数化与 SGD 噪声。
