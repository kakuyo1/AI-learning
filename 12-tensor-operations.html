1. 张量是什么？

张量 = 可以有任意多个维度的数字盒子。
标量、向量、矩阵都是它的特例。
熟悉的名字 张量说法 Rank Shape 例子
一个数 标量 scalar 0 ()
一排数 向量 vector 1 (3,)
一张表 矩阵 matrix 2 (2, 3)
一叠表 / 一批图 高维张量 3 / 4 (2,2,2) / (32,3,224,224)

深度学习常见形状：

  • 图像 (B, C, H, W)
  • 文本 (B, T, D)
  • 多头注意力 (B, H, T, D)

2. How memory layout works（内存布局）

内存是一维的。Stride 告诉程序：沿着某个轴走一步，要在内存里跳过多少个元素。

Row-major vs Column-major

布局 也叫 2×3 矩阵内存顺序 strides
Row-major C order（PyTorch/NumPy 默认） a b c d e f (3, 1) 行连续
Column-major F order（Fortran/MATLAB） a d b e c f (1, 2) 列连续

转置为什么很快？会 cache miss 吗？

转置通常不移动数据，只交换 strides → 张量变成 non-contiguous。

会有 cache miss。按新的「行」顺序访问时，内存地址跳跃，CPU cache 命中率下降，大矩阵上更明显。

主流解决办法：

  • .contiguous() / .copy()：真正重排内存
  • .reshape() 代替 .view()：非连续时更安全
  • 算子内部按 stride 优化（cuBLAS 等）
  • 少转置；或使用 channels_last 等更匹配的内存格式

3. Broadcasting rules（广播规则）

让不同形状的张量直接运算：从右边对齐，大小为 1 的维可自动扩展，几乎不复制数据。

两条核心规则：

  1. 从右边开始对齐
  2. 两维兼容 ⇔ 相等，或其中一个是 1；维度少的左边补 1
例子：(4, 3) + (3,)
(4, 3)
+
(3,) → 补1 → (1, 3)
→
结果 (4, 3)
易错点：结果不是 (5, 6)。广播不是把维度数字相加，而是「1 被扩展成对方的大小」，结果每维取兼容后的值。

真正的逐元素加减乘除，发生在形状对齐之后。

冲突例子：(5, 4) 与 (3, 1) → 第一维 5≠3 且都不是 1 → 报错

4. Einsum：万能张量运算

用字母给每个轴起名，写出「保留谁、求和谁」，一条表达式覆盖点积、矩阵乘、注意力等。
einsum("输入标记 -> 输出标记", 张量…)

三条规则：

  1. 每个轴一个字母
  2. 只在输入出现、输出没有的字母 → 被求和（收缩）掉
  3. 出现在输出的字母 → 保留
操作 Einsum 含义
点积 i,i-> 对 i 求和 → 标量
矩阵乘 ik,kj->ij 对 k 求和，保留 i,j
外积 i,j->ij 不求和，得到矩阵
转置 ij->ji 只换轴顺序
求迹 ii-> 对角线求和
批量 matmul bij,bjk->bik 保留 b，对 j 求和
注意力 QKᵀ bhtd,bhsd->bhts 对 d 求点积
注意力输出 bhts,bhsd->bhtd 对 s 加权求和

5. 「被求和（收缩）掉」是什么意思？

某个维度上：先对应相乘，再全部加起来，然后这个维度从结果里消失。

点积例子：

a=[1,2,3], b=[4,5,6]
1×4 + 2×5 + 3×6 = 32
原来的长度维 i 被「乘完再加」消掉了 → 变成标量

矩阵乘同理：对共享维 k 做 Σ，k 在结果中不再出现。

表达式 对字母的处理 结果
i,i-> 对 i 收缩 标量（点积）
i,j->ij 不收缩 矩阵（外积）
ik,kj->ij 对 k 收缩 矩阵（矩阵乘）

6. 其他常用操作速览

操作 作用
reshape 改形状，元素顺序不变（总数要一致）
squeeze / unsqueeze 去掉 / 加上大小为 1 的维（常为广播做准备）
transpose / permute 交换轴顺序；常只改 stride，可能非连续
sum / mean（reduction） 沿某轴聚合，该轴消失

7. 一句话速查

  • 张量 任意维的数字盒子；标量/向量/矩阵是特例
  • Stride 沿某轴走一步要跳过的元素数
  • Row-major 行连续（深度学习默认）；转置后可能非连续
  • Cache miss 非连续访问易发生；用 contiguous() 重排
  • 广播 右对齐，1 可扩展；不是维度数字相加
  • Einsum 字母标记轴；输出没有的字母被求和掉
  • 收缩 乘完再加，维度消失
最终记住：张量是多维数字的统一容器；stride 决定内存怎么走；广播对齐形状；einsum 用字母表达「保留与收缩」。把这四件事串起来，shape 错误和注意力里的张量操作都会清晰很多。
