具体优化问题： 最小化 f(x, y) = (x - 2.2)² + (y - 2.2)² + 0.5    约束 g(x, y) = x + y - 3.5 ≤ 0
无约束最小点在 (2.2, 2.2)，但 x + y = 4.4 > 3.5 不可行，因此最优解位于约束边界上。
目标函数 f(x) 等高线
约束 g(x) ≤ 0 (不可行域)
最优点 x* (KKT点)
μ 乘子 互补松弛
