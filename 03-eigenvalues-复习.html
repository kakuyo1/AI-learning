特征值 · 特征向量 · 特征分解

基于课程 03-matrix-transformations 的复习整理
覆盖特征值和行列式、满秩关系的全部关键问题

1. 核心概念（通俗版）

特征向量（Eigenvector）

矩阵作用后方向完全不变的特殊向量。它只被拉长或缩短，不会被旋转或扭歪。

特征值（Eigenvalue）

在这个特殊方向上被拉长/缩短的倍数，记作 λ。

A v = λ v

左边：矩阵作用在向量上；右边：只是把向量乘上一个数。方向完全一样。

一句话：特征向量 = 不被扭转的方向；特征值 = 这个方向上的拉伸倍数。

生活比喻

想象拉一块橡皮膜：大多数方向会被拉歪，但总有几个方向只变长短、不被扭歪。这些方向就是特征向量，变化的倍数就是特征值。

2. 怎么找到特征值和特征向量？

以课程例子为例：

A = [[2, 1],
      [1, 2]]

第一步：解特征方程求 λ

把方程改写成：

(A − λI) v = 0

要有非零解，必须让行列式等于 0：

det(A − λI) = 0

计算过程：

A − λI = [[2−λ, 1], [1, 2−λ]]

det = (2−λ)² − 1 = 0
(2−λ)² = 1
2−λ = ±1

→ λ = 3  或  λ = 1

第二步：把每个 λ 代回去求 v

λ A − λI 解出的特征向量
3 [[−1, 1], [1, −1]] [1, 1]（方向 y = x）
1 [[1, 1], [1, 1]] [1, −1]（方向 y = −x）

3. 为什么必须 det(A − λI) = 0？

这直接关系到「行列式 = 0 → 矩阵不可逆」这个核心性质。

情况 det(A−λI) 是否可逆 方程 (A−λI)v = 0 的解 是否是特征值
λ 是特征值 = 0 不可逆 有非零解（特征向量） 是
λ 不是特征值 ≠ 0 可逆 只有零解 否

如果矩阵可逆，两边乘逆矩阵只能得到 v = 0，没有意义。
只有当矩阵被“压扁”（不可逆）时，才存在非零向量被映射成零，这些向量就是特征向量。

本质：求特征值 = 寻找那些让 (A − λI) 变得不可逆的特殊 λ。

4. 行列式 · 满秩 · 可逆 的完整关系

这三个概念其实是同一件事的不同说法：

说法 条件 几何含义 对线性方程组的影响
满秩（Full Rank） rank = n
（n 为方阵边长）		 列向量线性无关，撑满整个空间 有唯一解
行列式不为 0 det(A) ≠ 0 平行四边形（平行六面体）面积/体积不为 0，没有被压扁 有唯一解
可逆（Invertible） 存在 A⁻¹ 变换可以完全还原回去 有唯一解
特征值全不为 0 所有 λ ≠ 0 没有任何方向被完全压成 0 有唯一解
等价关系（方阵）：
det(A) ≠ 0  ⇔  满秩  ⇔  可逆  ⇔  所有特征值 ≠ 0
反过来：
det(A) = 0  ⇔  秩不足（rank-deficient）  ⇔  不可逆  ⇔  至少有一个特征值 = 0
几何上：空间被压扁到更低的维度。

和特征值的直接联系

因为：

det(A) = λ₁ × λ₂ × … × λₙ

所以：

  • 只要有一个特征值是 0，行列式就变成 0，矩阵不满秩、不可逆
  • 所有特征值都不为 0，行列式就不为 0，矩阵满秩、可逆

这也解释了为什么「λ = 0 是特征值」意味着矩阵把某个方向完全压扁了。

5. 几何意义（和行列式的关系）

我们知道：

  • 行列式的绝对值 = 矩阵把单位正方形变成的平行四边形的面积
  • 也就是整体空间被放大了多少倍

特征值则把这个“整体放大”拆解成各个特殊方向上的单独放大：

对于 2×2 矩阵：

det(A) = λ₁ × λ₂

整体面积变化 = 各主轴拉伸倍数的乘积。

用例子验证：

  • λ₁ = 3（沿 [1,1] 拉长 3 倍）
  • λ₂ = 1（沿 [1,−1] 保持不变）
  • det(A) = 3 × 1 = 3，与直接计算 2×2 − 1×1 = 3 完全一致
几何画面：先转到特征向量坐标系 → 只做轴向拉伸 → 再转回去。
行列式就是所有轴向拉伸倍数的总效果。

6. 特征分解（Eigendecomposition）

如果矩阵有足够多的独立特征向量，可以写成：

A = V D V⁻¹
  • V：列是特征向量（新的坐标系）
  • D：对角矩阵，对角线上是特征值（只有缩放，没有旋转）
  • V⁻¹：把坐标系转回去

含义：任何复杂线性变换 =「换到特征坐标系 → 简单拉伸 → 换回来」。

7. 在 AI 领域的作用

应用 特征值 / 特征向量在做什么
PCA（主成分分析） 协方差矩阵的特征向量 = 数据变化最大的方向；特征值 = 该方向的方差大小。用来降维并保留最多信息。
RNN 稳定性 权重矩阵特征值 |λ| > 1 → 信号爆炸；|λ| < 1 → 信号消失。这是梯度爆炸/消失的根源之一。
谱聚类 / 图神经网络 用图拉普拉斯矩阵或邻接矩阵的特征向量来发现社区结构和图结构信息。
条件数 / 数值稳定性 最大特征值 / 最小特征值，判断矩阵是否病态（接近不满秩）。
优化与收敛 Hessian 矩阵的特征值影响优化算法的收敛速度。
AI 里的核心价值：告诉我们一个矩阵/变换在各个“本质方向”上放大或缩小的程度。

8. 一句话速查

  • 特征向量 矩阵作用后方向不变的特殊方向
  • 特征值 该方向上的拉伸/压缩倍数
  • 特征方程 det(A − λI) = 0，因为只有不可逆时才有非零解
  • 行列式与满秩 det ≠ 0 ⇔ 满秩 ⇔ 可逆 ⇔ 所有特征值 ≠ 0
  • 几何 det(A) = 所有特征值的乘积（面积/体积总缩放）
  • 特征分解 A = V D V⁻¹（换坐标系 → 拉伸 → 换回来）
  • AI 用途 PCA 降维、RNN 稳定性、谱方法、条件数分析
