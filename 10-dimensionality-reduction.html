10 Dimensionality Reduction

高可视化复习 · PCA · 解释方差 · 肘部法则 · t-SNE · UMAP · Kernel PCA · 重构误差

1. 这一课在讲什么？

高维数据其实有结构，只是你站的角度不对。
降维 = 找到真正重要的方向，把数据压到低维，同时尽量保住有用信息。

784 维的手写数字，人眼只需要几个关键信息就能认出是「7」。降维就是自动找出这些关键方向，砍掉冗余和噪声。

2. 为什么要降维？（维度灾难）

  • 距离失效：高维里任意两点距离都差不多，最近邻几乎没意义
  • 数据极度稀疏：空间大得填不满，模型难学
  • 计算与存储爆炸：特征一多，时间和内存都受不了

把维度降下来，这些问题会缓解很多。

3. PCA：找变化最大的方向

PCA 旋转坐标系，让第一轴对准数据波动最大的方向，第二轴次之……然后丢掉次要方向。

算法步骤：

  1. 中心化（每列减均值）
  2. 算协方差矩阵
  3. 特征分解 → 得到主成分方向（特征向量）和重要性（特征值）
  4. 按特征值从大到小排序
  5. 只保留前 k 个，做投影
X_reduced = (X − mean) @ W_k

特征值越大 = 该方向上的方差越大 = 越重要。

4. Explained Variance Ratio（解释方差比例）

每个主成分抓住了总方差的百分之多少：

解释方差比例 = 该主成分的特征值 / 所有特征值之和
主成分 解释比例 累计
PC147.3%47.3%
PC225.1%72.4%
PC311.2%83.6%
PC48.9%92.5%

用来判断「丢掉后面的成分会损失多少信息」。

5. Elbow Curve（肘部法则）选 k

把累计解释方差画成曲线：先陡后平。明显变平的「肘部」附近，就是候选的主成分个数 k。

累计解释方差 vs k（肘部示意）

三种选 k 策略：肘部法则、累计阈值（90%/95%）、看下游任务表现。

6. Reconstruction Error（重构误差）

降维再还原，和原始数据差了多少：

重构误差 = mean( (X − X̂)² )

对 PCA：重构误差 = 被丢掉的特征值之和。 用途：选 k、评估降维质量、异常检测（重构误差特别大的点可能是异常）。

7. t-SNE：保住邻居关系

目标：高维里靠近的点，降到 2D 后也尽量靠近。几乎只为可视化而生。
  • 在高维按距离定义邻居概率，在低维也构造类似分布
  • 用 KL 散度对齐两个分布，不断调整 2D 点位置
  • 低维用 t 分布解决「拥挤问题」，让簇分开
  • 关键参数：Perplexity（考虑多少邻居，常用 5～50）
簇间距离、相对位置没有可靠含义；有随机性；数据量大时很慢。不要直接当模型特征用。

8. UMAP：更快、全局更好

把数据看成流形上的邻居图，在低维重现这张图的连接关系。
t-SNE UMAP
速度 慢 更快
全局结构 较弱 通常更好
关键参数 Perplexity n_neighbors、min_dist
适用 小数据、强局部可视化 更大的数据、想兼顾全局

实用建议：数据量大优先 UMAP；只求最好看的局部簇且数据小，t-SNE 仍很强。

9. Kernel PCA：处理非线性结构

普通 PCA 只能做线性旋转。数据若是弯曲流形（同心圆、月牙），会失败。

Kernel PCA = 用核技巧在隐式高维特征空间里做 PCA，从而处理非线性。
  • 常用 RBF（高斯）核
  • 不显式计算高维坐标，只通过核函数算内积
  • 代价：要存 n×n 核矩阵，大数据吃力；可解释性变差

经典例子：两个同心圆，普通 PCA 分不开，RBF Kernel PCA 可以拉开。

10. 方法怎么选？

目标 优先选
预处理 / 压缩 / 给模型用 PCA
快速看线性结构 PCA（2D/3D）
2D 可视化，数据量小，要强局部簇 t-SNE
2D 可视化，数据较大，想兼顾全局 UMAP
数据明显非线性，PCA 效果差 Kernel PCA

11. 一句话速查

  • 降维 找真正重要的方向，砍掉冗余
  • PCA 线性，找方差最大方向，适合预处理
  • 解释方差比例 每个主成分占总方差的比例
  • 肘部法则 曲线变平处选 k
  • 重构误差 降维再还原损失了多少（PCA 中 = 丢掉的特征值之和）
  • t-SNE 保邻居，强可视化，慢，簇间距离不可信
  • UMAP 更快，全局结构更好的可视化方法
  • Kernel PCA 核技巧做非线性 PCA
最终记住：PCA 负责压缩与预处理；t-SNE/UMAP 负责画图看结构；Kernel PCA 负责非线性情况。选方法前先问自己：是为了喂模型，还是为了可视化？
