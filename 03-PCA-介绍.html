PCA 主成分分析

用最形象的方式理解「找到数据最重要的方向」· 含协方差矩阵详解与计算示例

1. PCA 到底在干什么？

PCA = 给数据找一组新的坐标轴，让这些轴按「信息量从多到少」排序，然后只保留最重要的几根轴。

想象你有一堆二维点（比如人的身高和体重）。这些点不是均匀散开的，而是大致沿着某个斜方向延伸。PCA 会自动找到这个「延伸最厉害」的方向，把它当作第一主成分，再找和它垂直的次要方向。

原始数据：点大致沿着斜方向分布
数据点

2. 为什么需要它？

  • 维度太高：特征有几百、几千维，计算慢、容易过拟合
  • 特征冗余：很多特征其实在说同一件事（高度相关）
  • 噪声：有些方向几乎没有变化，全是噪声
  • 可视化：高维数据没法直接画图，降到 2D/3D 才能看

PCA 的目标就是：用更少的维度，保留最多的信息。

3. 协方差矩阵是什么？（PCA 的关键输入）

协方差矩阵 = 一张描述「所有特征之间互相关系」的对称表格。

先分清两个概念

  • 方差（Variance）：一个特征自己变化有多大（身高大家差得多不多？）
  • 协方差（Covariance）：两个特征一起变化的程度（身高高的人，体重是不是也更重？）

矩阵长什么样？

假设有 3 个特征：身高、体重、年龄。协方差矩阵就是：

身高 体重 年龄
身高 身高方差 身高↔体重 身高↔年龄
体重 体重↔身高 体重方差 体重↔年龄
年龄 年龄↔身高 年龄↔体重 年龄方差
蓝色 = 自己的方差（对角线） 橙色 = 两两之间的协方差

因为「身高和体重的关系」跟「体重和身高的关系」完全一样，所以这个矩阵一定是对称的。
体重↔年龄 就是「体重和年龄这两个特征之间的协方差」。

数字怎么理解？

协方差的值 含义
很大正数 两个特征强烈正相关（一个大，另一个也倾向大）
接近 0 两个特征几乎没关系
很大负数 两个特征强烈负相关（一个大，另一个倾向小）

协方差怎么计算？（具体例子）

公式（人话版）：

Cov(体重, 年龄) = 把「每个人体重偏差 × 年龄偏差」全部加起来，再除以 (n−1)

用 4 个人的数据演示：

人 体重 (kg) 年龄
A6020
B7025
C8030
D9035

第 1 步：算平均值

  • 平均体重 = (60+70+80+90) / 4 = 75
  • 平均年龄 = (20+25+30+35) / 4 = 27.5

第 2 步：算每个人的偏差，再相乘

人 体重偏差
(体重 − 75)		 年龄偏差
(年龄 − 27.5)		 乘积
A −15 −7.5 (+112.5)
B −5 −2.5 (+12.5)
C +5 +2.5 (+12.5)
D +15 +7.5 (+112.5)

第 3 步：加总再平均

  • 所有乘积之和 = 112.5 + 12.5 + 12.5 + 112.5 = 250
  • 除以 (n−1) = 250 / 3 ≈ 83.33
结果：Cov(体重, 年龄) ≈ 83.33（较大的正数）→ 体重和年龄明显正相关（这个例子里年龄越大体重越重）。

实际写代码时直接用 NumPy：

import numpy as np
weight = np.array([60, 70, 80, 90])
age    = np.array([20, 25, 30, 35])
print(np.cov(weight, age))
# 得到的矩阵中，右上角（或左下角）就是 83.33

几何直觉（最重要）

协方差矩阵描述了数据点在空间中「长成什么形状」：

  • 数据像圆（各方向差不多）→ 协方差矩阵接近单位矩阵的倍数
  • 数据像斜着的长椭圆 → 协方差矩阵会清楚反映出「哪个方向拉得最长」
和 PCA 的直接关系：
数据 → 先算协方差矩阵 → 对它做特征分解 → 得到主成分（特征向量）和重要性（特征值）
PCA 的所有后续步骤，都建立在这张「关系表格」之上。没有协方差矩阵，就找不到「变化最大的方向」。

4. 核心直觉：找到「变化最大」的方向

数据点在空间中散开，有的方向拉得很长（方差大），有的方向压得很扁（方差小）。

PCA 会自动找到：

  • 第一主成分（PC1）：方差最大的方向（数据拉得最开的方向）
  • 第二主成分（PC2）：和 PC1 垂直，且方差次大的方向
  • 以此类推……
找到主成分：红色 = 第一主成分（最重要），绿色 = 第二主成分
PC1（方差最大） PC2（垂直且次大） 数据中心
关键洞察：PC1 和 PC2 一定互相垂直（正交）。这保证了新坐标轴互不冗余。

5. 和特征值、特征向量的关系

PCA 的数学本质就是对协方差矩阵做特征分解：

  • 特征向量 → 主成分的方向（PC1、PC2…）
  • 特征值 → 这个方向上的方差大小（有多「重要」）

特征值越大，说明数据在这个方向上拉得越开，信息量越多。

特征值大小 含义 PCA 怎么处理
很大 这个方向变化剧烈，信息丰富 保留（第一、第二主成分）
中等 有一定信息 根据需要决定保留几个
很小 / 接近 0 几乎没变化，主要是噪声或冗余 丢掉
丢掉小特征值对应的方向 = 主动做低秩近似，去掉冗余和噪声。

6. PCA 的完整步骤（形象版）

1
把数据中心化
让所有点的平均值变成原点（减去均值）。这样后续计算更干净。
2
算协方差矩阵
它描述了每两个特征之间的相关程度。对角线是各特征自己的方差。这是整个 PCA 的「输入地图」。
3
对协方差矩阵做特征分解
得到特征值和特征向量。特征向量就是新的坐标轴方向，特征值告诉你每个轴有多重要。
4
按特征值从大到小排序，选前 k 个
只保留最重要的 k 个方向（k 通常远小于原来的维度）。
5
把数据投影到这 k 个方向上
得到降维后的新数据。原来几百维，现在可能只剩 2～50 维。
投影到 PC1 上：从 2D 降到 1D（只保留最重要的方向）

所有点都被「拍扁」到最重要的那条轴上。虽然丢了垂直方向的信息，但保留了最大的变化。

7. 和「满秩 / 冗余」的关系

你之前问过：PCA 是不是在消除不满秩矩阵的重复特征？

部分正确，但不完整。

  • 如果某个特征值正好 = 0，说明这个方向完全没有信息（完美冗余），PCA 会丢掉它，矩阵因此变满秩。
  • 即使所有特征值都 > 0（矩阵满秩），只要有些特征值很小，PCA 也会主动丢掉它们，做「近似低秩」。

所以 PCA 的目标不是「强行让矩阵满秩」，而是按重要性排序，主动丢掉不重要的方向。满秩只是顺带的结果之一。

8. 一个生活类比

假设你用 10 个问题评价一个人的性格：

  • 「你开朗吗？」「你外向吗？」「你喜欢聚会吗？」…… 这些问题其实高度相关，都在测「外向性」。
  • 「你做事有条理吗？」「你喜欢计划吗？」…… 测的是「尽责性」。

PCA 会发现：前几个问题其实在说同一件事，可以合并成「外向性」这一个主成分；后几个合并成「尽责性」。最终可能只用 2～3 个主成分就能概括原来 10 个问题的大部分信息。

协方差矩阵在这里的作用，就是先量化「这些问题两两之间相关有多强」，然后特征分解才能找出真正独立的性格维度。

9. 一句话总结

PCA = 先用协方差矩阵看清特征之间的关系 → 找到数据变化最大的方向（特征向量）→ 按重要性排序（特征值）→ 只保留最重要的几个，从而降维、去冗余、去噪声。
概念 在 PCA 里是什么
协方差矩阵 描述特征之间「一起变化」关系的对称表格（PCA 的输入）
特征向量 主成分的方向（新坐标轴）
特征值 该方向上的方差（重要性）
投影 把数据「拍」到选中的主成分上
降维 丢掉小特征值对应的方向
