06 Probability and Distributions

高可视化复习 · 概率基础 · Softmax · 交叉熵 · 采样 · 语言模型综合例子

1. 为什么学概率？

概率是 AI 用来表达「不确定性」的语言。
模型的每次预测都是一个概率分布，损失函数衡量两个分布有多不像，训练就是让预测分布靠近真实分布。

2. 事件、样本空间与概率

  • 样本空间 S：所有可能结果的集合（抛硬币 {正, 反}）
  • 事件：样本空间的子集（「掷出偶数」）
  • 概率：给事件一个 0~1 的数字
三条公理：
  1. 概率永远 ≥ 0
  2. 整个样本空间概率 = 1
  3. 互斥事件概率可相加

条件概率与独立性

P(A|B) = P(A 且 B) / P(B)

独立：知道一件事对另一件事没有影响 → P(A 且 B) = P(A) × P(B)

3. PMF vs PDF

类型 名称 特点 ML 例子
离散 PMF（概率质量函数） 每个值都有直接概率，和为 1 分类输出、Softmax
连续 PDF（概率密度函数） 单点概率为 0，积分才有概率；密度可 >1 VAE 潜在空间、权重初始化

4. 常见分布速查

分布 一句话 ML 中的用途
Bernoulli 一次试验两个结果 二分类、Dropout
Categorical 一次试验 k 个结果 多分类 Softmax 输出
Uniform 所有结果一样可能 随机初始化
Normal (Gaussian) 钟形曲线，由 μ、σ 决定 权重初始化、噪声建模
Poisson 固定时间内稀有事件次数 计数类问题
中心极限定理：很多独立随机变量加在一起，最终都会变成正态分布。这就是为什么高斯到处都是。

5. 期望与方差

  • 期望 E[X]：加权平均（结果 × 概率再求和）
  • 方差：偏离均值的平均平方程度

损失函数本质上是「在数据分布上的期望损失」。

6. 对数概率（Log Probabilities）

直接乘很多小概率会下溢变成 0。
取对数后乘法变加法，数值稳定。
log(a × b × c) = log a + log b + log c
  • 对数概率永远 ≤ 0
  • 越负表示越不可能
  • 交叉熵损失 = 正确类别的负对数概率

7. Softmax 详细讲解

Softmax = 把一组任意实数（logits）变成合法概率分布的标准方法。
softmax(z_i) = exp(z_i) / Σ exp(z_j)

为什么叫 Softmax？

它是「软」的最大值：

  • Hardmax / Argmax：最大的变成 1，其余全 0（不可导）
  • Softmax：最大的占优势，但其余也留一点概率（光滑可导）
Hardmax vs Softmax 对比

数值稳定技巧

先减最大值再 exp：z_shifted = z - max(z)
结果完全一样，但不会溢出

Log-Softmax

直接计算 log(softmax(z))，数值更稳定。交叉熵损失内部就用它。

8. 交叉熵损失 = 正确类别的负对数概率

假设模型输出：P(猫)=0.1, P(狗)=0.7, P(鸟)=0.2
真实答案是「狗」。

我们只关心正确类别的概率 0.7：

交叉熵损失 = -log(0.7) ≈ 0.357
  • 概率 = 1.0 → 损失 = 0（完美）
  • 概率 = 0.7 → 损失 ≈ 0.357
  • 概率接近 0 → 损失趋向 +∞（严厉惩罚）
训练目标：拼命把这个数字压小，让模型给正确答案的概率尽量接近 1。

9. 采样（Sampling）

采样 = 按照概率分布的「剧本」，随机演出一个具体结果。
场景 在采样什么
Dropout 哪些神经元被关掉（伯努利）
数据增强 随机裁剪、翻转参数
语言模型生成 下一个词（从预测分布采样）
扩散模型 噪声，再逐步去噪
VAE 潜在空间的向量

温度 Temperature

softmax(z_i / T)
  • T → 0：几乎总是选最大的（确定但死板）
  • T = 1：正常
  • T → ∞：接近均匀（多样但容易胡说）

10. 综合例子：语言模型如何用到这些概念

假设一个极简语言模型，词表只有 4 个词：{我, 爱, 你, 啊}

完整流程可视化
上文「我」
→
模型
→
logits
→
Softmax
→
概率分布

第 1 步：模型输出 logits

词： 我 爱 你 啊
logits：[1.0, 3.0, 0.5, 0.1]

第 2 步：Softmax 变成概率（Categorical 分布）

先减最大值 3.0 → [-2.0, 0.0, -2.5, -2.9]
exp 后归一化 ≈ [0.09, 0.72, 0.06, 0.04]

这就是一个合法的概率分布（PMF），所有概率 ≥0 且和为 1。

第 3 步：训练时算交叉熵损失

假设真实下一个词是「爱」（索引 1）：

损失 = -log(0.72) ≈ 0.328

如果模型给「爱」的概率更高，损失会更小；如果几乎没给，损失会非常大。

第 4 步：生成时采样

训练好后，要生成下一个词：

  • Argmax：永远选「爱」（最稳，但没有多样性）
  • 采样：按 [0.09, 0.72, 0.06, 0.04] 的概率随机抽一个词
  • 加温度 T=0.7：分布更尖锐，更倾向选高概率词
  • 加温度 T=1.5：分布更平坦，更容易选出「我」「你」「啊」
整条链路用到的概率知识：
  1. 模型输出的是 Categorical 分布的参数（logits）
  2. Softmax 把它变成合法的 PMF
  3. 交叉熵 = 正确词的负对数概率（衡量预测分布和真实分布的差距）
  4. 生成时从预测的分布中采样，得到具体的下一个词
  5. 温度控制采样的「随机程度」
这就是概率在语言模型里的完整闭环：用分布表达不确定性 → 用交叉熵训练 → 用采样生成。

11. 一句话速查

  • 概率 AI 表达不确定性的语言
  • PMF / PDF 离散概率 vs 连续密度
  • Softmax 把 logits 变成概率分布（软的最大值）
  • 交叉熵 -log(正确类别概率)，训练的核心损失
