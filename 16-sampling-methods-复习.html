1. 为什么采样重要

语言模型算出 5 万个词的概率后必须选一个：永远选最高 → 死板；完全乱选 → 胡话。中间地带由采样策略控制。
  • 生成：词、图、语音
  • 训练：batch、Dropout、增强
  • 估计：期望、积分（解不出就抽样平均）
  • 探索：RL 轨迹、后验

2. 均匀随机 · CDF · 逆变换采样

只有「0～1 公平骰子」，却想模拟「小雨多、暴雨少」。需要把公平随机数映射成符合目标规律的数值。

CDF 是什么？

F(x) = P(X ≤ x)：不超过 x 的总概率。从 0 升到 1，单调不减。连续时等于 PDF 从左边积到 x 的面积。

PDF 左侧累积面积 = CDF 在 x 处的高度

逆变换采样

1) 抽 u ~ Uniform(0, 1)
2) x = F 的反函数 (u)
→ x 服从目标分布
逆变换：概率轴上的 U → 数值轴上的 x
没有简单 F 反函数时（如正态），换其他方法。

3. 拒绝采样

想按不规则「人气地图」点名，却只能在大矩形里均匀扔飞镖：扎在人气轮廓内就留下，否则重扔。
需要：p(x) ≤ M · q(x) 对所有 x 成立
抽 x~q，再抽 u~U(0,1)
若 u < p(x)/(M·q(x)) → 接受，否则拒绝
在包络下扔点，落在绿线下方才保留

4. 重要性采样

想知道真实顾客分布 p 下的平均消费，问卷却按方便的 q 拦人。给每人乘权重 w = p/q：在 p 里重要、在 q 里少见的人，话语权更大。
E_p[f] ≈ 平均 [ f(xᵢ) · w(xᵢ) ]，其中 w = p/q
或自归一化：Σ w·f / Σ w
从 q 抽样，用权重纠正到 p 下的期望
q 与 p 差太远 → 少数权重爆炸，估计不稳（PPO 里常 clip 权重）。

5. 蒙特卡洛估计

不规则湖面积难算：在大矩形里随机扔豆子，用「落在湖内的比例 × 矩形面积」近似湖面积。
E[f(X)] ≈ (1/N) × Σ f(xᵢ)
误差大致随 1/√N 下降（与维度无关）
经典：扔点估 π

6. MCMC · Metropolis-Hastings

目标像一座复杂的山（只知道相对高度）。随机走：上坡多半走，下坡按比例偶尔走，避免卡在小山包。走久了，待在各处的时间比例 ≈ 目标分布。
提议 x' ~ q(·|当前 x)
α = min( 1, p(x')/p(x) )　（对称提议时）
以概率 α 走到 x'，否则留下
随机游走 + 按密度比接受；需 burn-in；步长太大太小都不好

7. Gibbs 采样

身高、体重联合难一次抽：先固定体重抽身高，再固定新身高抽体重，轮流更新。
沿坐标轴交替更新；强相关时混匀慢

8. LLM：Temperature · Top-k · Top-p

写小说：有时要稳，有时要活，还要少出胡话。三个旋钮分工不同。
方法做什么特点
Temperaturelogits / T 再 SoftmaxT 小更尖；T 大更平；不删词
Top-k只留概率最高 k 个k 固定，可能过宽或过窄
Top-p累计概率达 p 的最小前缀自信时核小，犹豫时核大
Top-p：只保留「概率质量够 p」的核

9. 重参数化技巧（VAE）

编码器给出 μ、σ，要从 N(μ, σ²) 抽 z 再解码。直接「z ~ 该正态」会挡住梯度；必须把随机和参数拆开。
步骤① ε ~ 标准正态 N(0, 1)　← 不含参数
步骤② z = μ + σ × ε　　　　← 只含可导加乘
梯度：∂z/∂μ = 1，　∂z/∂σ = ε
上：随机挡路 · 下：噪声在外，参数在公式里

10. Gumbel-Softmax

离散选类别也要采样，硬 argmax 同样截断梯度。需要「像抽类别、又略可导」的近似。
gᵢ ~ Gumbel(0,1)
yᵢ = softmax( (log pᵢ + gᵢ) / τ )
τ → 0 更接近 one-hot；τ 大更软

直通估计：前向用硬 argmax，反向当软 y 求导。

11. 分层采样

估整条街平均房价：完全随机可能都抽到北段。改成切成 N 段，每段都抽一家 → 覆盖均匀、方差更小。
xᵢ = (i + Uᵢ) / N，Uᵢ ~ Uniform(0,1)，每层一个点
每层必有一点，避免扎堆与空洞

12. 与扩散模型的联系

无法直接从「所有自然照片」分布抽图。扩散：先把图一步步加噪成纯噪声；生成时从噪声出发，一步步采样「更干净一点」的图。
前向加噪（重参数化）· 反向多步去噪采样 · 训练用蒙特卡洛

13. 一句话速查

  • CDF P(X≤x) = PDF 左侧面积
  • 逆 CDF x = F⁻¹(U)
  • 拒绝 包络下扔点，按 p/(M q) 接受
  • 重要性 从 q 抽，权重 p/q 估 E_p
  • 蒙特卡洛 平均≈期望，误差 ~ 1/√N
  • MH 随机走 + 密度比接受
  • Gibbs 按条件分布逐维更新
  • Temperature 拉尖/拉平
  • Top-k / Top-p 截长尾；p 自适应核大小
  • 重参数化 z = μ + σ·ε，可反传
  • Gumbel-Softmax 离散可导近似
  • 分层 每层都抽，降方差
  • 扩散 多步去噪 = 采样思想综合
口诀：简单随机数 → 变换 / 拒绝 / 加权 / 乱走 → 复杂样本或期望；要训练则随机在外、参数在可导式子里。
