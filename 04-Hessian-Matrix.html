Hessian Matrix · 复习文档

基于 04-calculus-for-ml 课程与问答整理 · 二阶偏导 · 几何含义 · 实际近似方法

1. Hessian 矩阵是什么？

梯度告诉你「坡度」（一阶信息），Hessian 告诉你「弯曲程度」（二阶信息）。

它是由所有二阶偏导数组成的矩阵。

对于两个变量的函数 f(x, y)：

H = | ∂²f/∂x² ∂²f/∂x∂y |
    | ∂²f/∂y∂x ∂²f/∂y² |

每个元素都是「对某个变量再求一次导」的结果。

2. 二阶偏导如何计算？

二阶偏导 = 在一阶偏导的基础上，再求一次导。

符号 含义
∂²f/∂x² 先对 x 求偏导，再对 x 求偏导（纯二阶）
∂²f/∂y² 先对 y 求偏导，再对 y 求偏导（纯二阶）
∂²f/∂x∂y 先对 y 求偏导，再对 x 求偏导（混合偏导）

混合偏导通常满足：∂²f/∂x∂y = ∂²f/∂y∂x（顺序可交换）。

具体例子

函数：f(x, y) = x² + 3xy + y²

第一步：一阶偏导

  • ∂f/∂x = 2x + 3y
  • ∂f/∂y = 3x + 2y

第二步：二阶偏导

  • ∂²f/∂x² = 对 (2x + 3y) 再对 x 求导 → 2
  • ∂²f/∂y² = 对 (3x + 2y) 再对 y 求导 → 2
  • ∂²f/∂x∂y = 对 (3x + 2y) 再对 x 求导 → 3
  • ∂²f/∂y∂x = 对 (2x + 3y) 再对 y 求导 → 3
H = | 2 3 |
    | 3 2 |

另一个例子（马鞍面）

f(x, y) = x² − y²

  • 一阶：∂f/∂x = 2x，∂f/∂y = −2y
  • 二阶：∂²f/∂x² = 2，∂²f/∂y² = −2，混合 = 0
H = | 2 0 |
    | 0 −2 |

3. 几何含义（最重要）

把损失函数想成一座山的地形。当梯度 = 0 时，用 Hessian 判断这个点是什么：

Hessian 的性质 地形长什么样 对应的点
所有特征值 > 0（正定） 碗口朝上的碗 局部最小值
所有特征值 < 0（负定） 碗口朝下的碗 局部最大值
有正有负（不定） 马鞍形状（一边上、一边下） 鞍点
上面 x² − y² 的例子，特征值是 +2 和 −2（一正一负）→ 鞍点。
而 x² + y² 的 Hessian 特征值都是正的 → 局部最小值。

4. 和梯度下降 / 牛顿法的关系

普通梯度下降只看一阶信息（斜率）：

w_新 = w_旧 − 学习率 × 梯度

牛顿法会用到 Hessian：

w_新 = w_旧 − Hessian⁻¹ × 梯度

Hessian 的作用是根据弯曲程度自动调整步长：

  • 很陡的方向 → 步子自动变小（防止冲过）
  • 很平的方向 → 步子自动变大（加快前进）
因此牛顿法通常收敛更快，但计算代价极高。

5. 为什么深度学习几乎不直接算完整 Hessian？

一个有 N 个参数的模型，完整 Hessian 是 N × N 的矩阵。
N = 100 万 → 矩阵有 1 万亿 个元素，根本存不下、也算不起。

所以必须使用各种廉价近似。

6. 实际中如何获得二阶信息的好处？

方法 核心思想 代表 代价
只用一阶 + 动量 完全不管二阶，用历史梯度加速 SGD + Momentum 最低
自适应学习率
（对角线近似）		 只估计每个参数自己的二阶信息 Adam、RMSProp、AdaGrad 很低
有限内存拟牛顿 用最近几次梯度变化近似 Hessian 的逆 L-BFGS 中等
K-FAC / 自然梯度 用 Fisher 信息矩阵近似 K-FAC 较高
Hessian-向量积 不显式构造矩阵，只算 H × 向量 曲率分析、二阶优化研究 中等

目前工业界最主流的做法：Adam

Adam 给每个参数维护一个「自己的学习率」，这个学习率会根据该参数历史梯度的大小自动调整。

本质上是在用一种非常粗糙的对角线 Hessian 近似：

  • 梯度一直很大的参数 → 学习率自动变小（对应曲率大）
  • 梯度一直很小的参数 → 学习率自动变大（对应曲率小）

虽然粗糙，但效果出奇地好，计算开销几乎和普通 SGD 一样。

什么时候会用到更接近真正 Hessian 的方法？

  • 小模型 / 凸优化问题 → 可直接用 L-BFGS 或牛顿法
  • 需要极致收敛速度的场景 → K-FAC 或自然梯度
  • 研究损失地形、曲率分析 → Hessian-向量积
  • 二阶剪枝、量化感知训练等特殊任务 → 估计对角或块对角 Hessian

7. 一句话速查

  • Hessian 由所有二阶偏导数组成的矩阵，描述函数的弯曲程度
  • 二阶偏导 在一阶偏导基础上再求一次导
  • 正定 所有特征值 > 0 → 局部最小值（碗）
  • 负定 所有特征值 < 0 → 局部最大值
  • 不定 有正有负 → 鞍点（马鞍）
  • 牛顿法 用 Hessian⁻¹ × 梯度，根据曲率自动调步长
  • 实际做法 几乎不算完整 Hessian，而是用 Adam 等对角线近似
核心结论：梯度告诉你往哪走，Hessian 告诉你这个坡弯曲得怎么样。深度学习里用廉价近似（尤其是 Adam）来获得二阶信息的好处。
