Jacobian Matrix · 复习文档

通俗理解版 · 带可视化 · 与梯度、Hessian 的关系 · 在深度学习中的作用

1. 最通俗的理解

Jacobian = 一张记录「每个输入对每个输出影响有多大」的表格。

想象你在调一台音响，有 3 个旋钮（输入）：低音、中音、高音。
音响会输出 2 个结果：音量大小、声音是否刺耳。

你想知道：「我轻轻转一下某个旋钮，两个结果分别会怎么变？」

Jacobian 就是这张「影响关系表」

2. 正式一点的定义

当函数有多个输入、多个输出时，Jacobian 把所有一阶偏导数排成一个矩阵。

假设 2 个输入 (x, y)，2 个输出 (u, v)：

u = f(x, y)
v = g(x, y)

Jacobian 矩阵就是：

J = | ∂u/∂x ∂u/∂y |
    | ∂v/∂x ∂v/∂y |

每一行对应一个输出，每一列对应一个输入。

输入如何影响输出（箭头粗细示意影响大小）
来自 x 的影响 来自 y 的影响

3. 具体数字例子

函数：

u = 2x + y
v = 3x − y

直接求偏导后得到：

J = | 2 1 |
    | 3 −1 |

含义：

  • x 增加一点点 → u 大约增加 2 倍，v 大约增加 3 倍
  • y 增加一点点 → u 大约增加 1 倍，v 大约减少 1 倍

4. 和梯度、Hessian 的对比

三者的关系（形状对比）
概念 输入 / 输出 内容 形状
梯度 Gradient 多输入 → 1 个输出 一阶偏导数 向量
Jacobian 多输入 → 多输出 一阶偏导数 矩阵
Hessian 多输入 → 1 个输出 二阶偏导数 矩阵
可以简单记：Jacobian = 向量值函数的「梯度」。
当只有一个输出时，Jacobian 就退化成普通的梯度向量。

5. 几何直觉

输入空间的一个小变化（小箭头），经过函数后会变成输出空间里的另一个小箭头。

Jacobian 描述的就是这个「小箭头如何被本地线性变换」——函数在某点附近表现得像一个矩阵乘法。

小变化如何被 Jacobian「拉伸/旋转」

Jacobian 把输入的小箭头变成输出的小箭头（可能被拉长、缩短、旋转）

6. 在深度学习中的作用

  1. 反向传播的本质
    每一层神经网络都是「一堆输入 → 一堆输出」。框架在反向传播时，其实就是在算每一层的 Jacobian，然后和后面传来的梯度相乘（链式法则）。你平时看不到，是因为全自动完成了。
  2. 多输出情况
    当损失不是单一标量，或需要同时对多个输出求梯度时，就会用到 Jacobian。
  3. 归一化流（Normalizing Flows）等
    需要计算 Jacobian 的行列式（det J），用来追踪概率密度的变化。
  4. 敏感度分析 / 可解释性
    看输入的微小变化会如何影响各个输出。

7. 一句话速查

  • Jacobian 记录「每个输入对每个输出影响有多大」的矩阵
  • vs 梯度 梯度是多输入单输出；Jacobian 是多输入多输出
  • vs Hessian Jacobian 是一阶，Hessian 是二阶
  • 深度学习 反向传播时每一层都在隐式使用它，框架自动计算
  • 记忆口诀 有多个输出时才需要完整的 Jacobian；单个输出时它就是梯度
最终记住：Jacobian 就是一张「影响关系表」，把所有输入对所有输出的一阶影响一次性写清楚。
