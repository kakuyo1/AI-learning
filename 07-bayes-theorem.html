07 Bayes' Theorem

高可视化复习 · 贝叶斯定理 · Naive Bayes · MLE vs MAP · 频率派 vs 贝叶斯派

1. 核心思想

概率是关于你预期什么，贝叶斯定理是关于你学到了什么。
你先有一个看法（先验），看到新证据后，用严格的规则更新看法（后验）。

2. 贝叶斯定理公式

P(A|B) = P(B|A) × P(A) / P(B)
符号 名称 含义
P(A|B) 后验 Posterior 看到证据 B 之后，对 A 的新看法
P(B|A) 似然 Likelihood 如果 A 为真，出现证据 B 的可能性
P(A) 先验 Prior 看到证据之前，对 A 的看法
P(B) 证据 Evidence 证据本身出现的总概率（归一化项）
P(B) = P(B|A)·P(A) + P(B|¬A)·P(¬A)

3. 经典例子：医学检测

疾病发病率 1/10000，检测准确率 99%（真阳性 99%，假阳性 1%）。你测出阳性，真正生病的概率是多少？

P(sick) = 0.0001
P(positive|sick) = 0.99
P(positive|healthy) = 0.01

P(positive) = 0.99×0.0001 + 0.01×0.9999 ≈ 0.0101
P(sick|positive) = 0.99×0.0001 / 0.0101 ≈ 0.98%
很多人直觉觉得是 99%，真正答案不到 1%。因为没病人远多于病人，假阳性数量会很多。先验（疾病罕见）起了主导作用。

4. 垃圾邮件例子

P(spam) = 0.3
P("lottery"|spam) = 0.05
P("lottery"|not spam) = 0.001

P(spam|"lottery") ≈ 95.5%

一个词就把概率从 30% 推到 95.5%。真正的垃圾邮件过滤器会对成百上千个词同时做这件事。

5. Naive Bayes（朴素贝叶斯）

用贝叶斯定理做分类，并假设所有特征在给定类别下相互独立。
P(class | features) ∝ P(class) × P(f1|class) × P(f2|class) × … × P(fn|class)

「朴素」就朴素在这个独立假设。现实中词和词并不独立，但这个假设让计算变得极快，而且在文本分类上效果意外地好。

实际实现要点：
  • 用词频统计估计 P(word|class) → 这是 MLE
  • Laplace 平滑：避免某个词概率为 0 导致整条乘积归零
  • 用对数概率相加，防止下溢

6. MLE vs MAP

MLE（最大似然） MAP（最大后验）
目标 最大化 P(数据|参数) 最大化 P(参数|数据)
是否用先验 不用 用（似然 × 先验）
数据很少时 容易极端 更稳健
ML 对应 无正则训练 L2 / L1 正则
高斯先验 → L2 正则
拉普拉斯先验 → L1 正则
你每次加正则项，其实都在做贝叶斯声明：「我事先认为参数大概长这样」。

7. Bayesian vs Frequentist（实际区别）

方面 频率派 Frequentist 贝叶斯派 Bayesian
概率含义 长期频率 信念程度
参数看法 固定但未知的常数 随机变量（有分布）
输出 点估计 完整分布
不确定性 置信区间（关于程序） 可信区间（关于参数）
小数据 容易过拟合 先验起正则作用
计算 通常更快 常需采样（MCMC）
大多数生产环境的深度学习是频率派（SGD + 点估计）。
贝叶斯方法在需要「知道自己不知道」或数据很少时更有价值。

8. 为什么贝叶斯思维对 ML 重要

Priors are regularization

高斯先验 = L2，拉普拉斯先验 = L1。加正则就是在做贝叶斯声明。

Posteriors are uncertainty

普通模型只给一个概率数字，贝叶斯给分布：「我认为 P(spam) 在 0.8~0.95 之间」。

Bayes updates are online learning

今天的后验变成明天的先验。新数据来了就增量更新，不用从头训练。

Model comparison is Bayesian

边际似然、Bayes Factor、BIC 用贝叶斯方式权衡拟合与复杂度，避免过拟合。

9. 贝叶斯更新流程

先验 → 证据 → 后验
先验 Prior
P(A)
+
证据 / 似然
P(B|A)
→
后验 Posterior
P(A|B)

后验可以继续作为下一轮的先验，实现持续学习

10. 一句话速查

  • 贝叶斯定理 P(A|B) = P(B|A)·P(A) / P(B)，用证据更新信念
  • Naive Bayes 假设特征独立的贝叶斯分类器，简单高效
  • MLE 只让数据最可能出现的参数（无正则）
  • MAP 数据 + 先验，对应 L1/L2 正则
  • 频率派 参数固定未知，输出点估计
  • 贝叶斯派 参数有分布，输出不确定性
  • 正则化 本质上是把先验写进损失函数
最终记住：贝叶斯定理教我们如何正确地用新证据更新旧看法。它给了正则化、不确定性、在线学习、模型比较一个统一的视角。
