1. 损失函数是什么？

损失函数 = 模型现在有多「错」的一个数字。
数字越大 → 错得越厉害；数字越小 → 越接近正确答案。

损失大

预测偏离真实值很远，或非常自信地猜错。
就像考试得了很低分。

损失小

预测已经很接近真实答案。
就像考试得了高分（分数是倒过来的）。

生活比喻：把模型想象成射箭的人。

  • 损失 = 箭离靶心的距离
  • 损失大 = 经常脱靶（容易错）
  • 损失小 = 箭都集中在靶心附近（更可能做对）
我们训练的唯一目标：拼命把这个「错误数字」往小了降。

2. 偏导数（Partial Derivative）

偏导数 = 只动一个变量、冻住其他所有变量时，函数的变化率。

神经网络的损失依赖成千上万个权重。偏导数回答的是：

「如果我只轻轻拧这一颗旋钮，损失会上升还是下降？变多快？」

例子：f(x, y) = x² + 3xy + y²

  • 对 x 的偏导数：把 y 当成常数 → 2x + 3y
  • 对 y 的偏导数：把 x 当成常数 → 3x + 2y

几何直觉：把损失看成一座山，x 和 y 是地面两个方向。

  • ∂f/∂x = 沿着 x 方向走时的山坡斜率
  • ∂f/∂y = 沿着 y 方向走时的山坡斜率

3. 梯度与梯度下降

把所有偏导数组成一个向量，就是梯度：

∇f = [ ∂f/∂x , ∂f/∂y , … ]

梯度指向最陡的上坡方向。要让损失变小，就往相反方向走。

w_新 = w_旧 − 学习率 × (∂L/∂w)

为什么顺着梯度下降，模型就会变好？

1
模型用当前权重做出预测，算出损失（现在有多错）
2
对每个权重算偏导数，知道「往哪拧能让损失变小」
3
所有权重一起按这个方向调一点点
4
损失下降 → 模型比刚才更准了一点点
每走一步都在主动减小错误，所以模型会一点点变好。

4. 全局最小值 · 局部最小值 · 斜率

概念 通俗理解 对训练的影响
Global minimum
全局最小值		 整座山里最低的那个点 理想目标，模型最好的状态
Local minimum
局部最小值		 附近比周围都低，但不是全山最低 可能卡住，得到次优解
Slope
斜率 / 梯度		 当前位置的倾斜程度和方向 告诉算法「往哪走、走多快」
重要现实：高维空间里局部最小值通常没有想象中可怕，很多已经足够好用。学习率太大可能跳过谷底，太小则走得极慢。
梯度下降不保证一定找到全局最小值，但每一步（学习率合理时）几乎都能让损失下降。

5. Numerical vs Analytical Derivatives

类型 怎么算 优点 缺点
Analytical
解析导数		 用手 / 公式直接求导
（如 x² → 2x）		 精确、极快 必须知道公式并会推
Numerical
数值导数		 用微小变化近似斜率
(f(x+h) − f(x−h)) / 2h		 对任何函数都有效，实现简单 有误差、速度慢

在深度学习中的实际使用：

  • 训练时（反向传播）→ 主要用解析（自动微分）
  • 检查梯度对不对 → 用数值做验证（Gradient Check）
  • 现代框架用的是更高级的自动微分，结合了两者优点

7. 链式法则（The Chain Rule）

链式法则 = 复合函数的导数，等于各层导数相乘。
它是反向传播的灵魂。

当函数一层套一层时：

y = f( g(x) )
dy/dx = f'(g(x)) · g'(x)

生活比喻：推倒多米诺骨牌。最终结果的变化 = 每一环传递过来的变化乘在一起。

在神经网络中的意义

网络是典型的函数套函数：

输入 x
→
线性 wx+b
→
激活函数
→
…
→
损失 L

要知道早期权重对最终损失的影响，必须把中间所有层的导数乘起来。这就是反向传播。

8. 链式法则完整数值例子（综合演示）

这是一个最简单但完整的小网络，把「损失 → 梯度流动 → 权重更新 → 损失下降」全部走一遍。

网络结构：

z = w · x + b
a = σ(z) = 1 / (1 + e⁻ᶻ)　　（Sigmoid）
L = (a − y)²　　（均方误差）

具体数字：

  • 输入 x = 2
  • 权重 w = 0.5
  • 偏置 b = −1
  • 真实标签 y = 1

第 1 步：前向传播（算出当前损失）

  1. z = 0.5 × 2 + (−1) = 0
  2. a = σ(0) = 1 / (1 + e⁰) = 0.5
  3. L = (0.5 − 1)² = 0.25

现在损失是 0.25。我们想知道：如果改 w，损失会怎么变？

第 2 步：反向传播（用链式法则求 ∂L/∂w）

∂L/∂w = (∂L/∂a) × (∂a/∂z) × (∂z/∂w)
步骤 计算过程 结果
∂L/∂a 2(a − 1) = 2(0.5 − 1) −1
∂a/∂z Sigmoid 导数 a(1−a) = 0.5 × 0.5 0.25
∂z/∂w z = w·x + b，对 w 求导就是 x 2
相乘（链式法则） (−1) × 0.25 × 2 −0.5

第 3 步：更新权重

假设学习率 η = 0.1：

w_新 = w_旧 − η × (∂L/∂w)
w_新 = 0.5 − 0.1 × (−0.5) = 0.55

第 4 步：验证有没有变好

用新的 w = 0.55 再算一遍：

  • z = 0.55 × 2 − 1 = 0.1
  • a = σ(0.1) ≈ 0.525
  • L = (0.525 − 1)² ≈ 0.226
损失从 0.25 → 0.226，确实下降了！模型比刚才更准了一点点。
梯度流动路径（从损失一路乘回到权重）
损失 L
× (−1)
激活 a
× 0.25
中间量 z
× 2
权重 w

最终梯度 = (−1) × 0.25 × 2 = −0.5

这就是链式法则在神经网络里的完整工作方式：从最终损失开始，一层一层把局部导数乘回去，得到每个参数该怎么调。

9. 一句话速查

  • 损失函数 衡量模型有多错的数字，训练目标是让它变小
  • 偏导数 只动一个变量时函数的变化率
  • 梯度 所有偏导数组成的向量，指向最陡上坡
  • 梯度下降 反着梯度走，让损失一步步下降
  • 全局/局部最小 全山最低 vs 附近最低（可能卡住）
  • 解析 vs 数值导数 公式直接算 vs 用微小变化近似
  • 链式法则 复合函数导数 = 各层导数相乘（反向传播核心）
