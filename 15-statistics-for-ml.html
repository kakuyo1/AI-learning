15 Statistics for Machine Learning

详细复习 · 描述统计 · 相关 · 假设检验 · t/卡方 · A/B · 效应量 · Bootstrap · CLT

统计的作用：区分「模型真的更好」还是「只是运气好」。没有区间、检验和效应量，上线的可能只是噪声。

1. 描述统计

中心趋势

  • 均值：平衡点，对异常值敏感
  • 中位数：排序后正中，更稳健
  • 众数：出现最多的值，分类变量更有用
均值 ≫ 中位数 → 常为右偏（长尾在右，如收入）。
训练 loss 常见「多数样本很容易、少数很难」→ 右偏 → 均值往往 > 中位数；应同时看分位数。

离散程度

  • 方差 / 标准差：相对均值的波动；标准差与原数据同单位
  • 范围：max−min，极不稳健
  • IQR：Q3−Q1，中间 50% 的跨度，较稳健

分位数（P50 / P95 / P99）

ML 中特别关心：推理延迟、置信度分布、误差尾部。

平均误差低但 P99 误差极差 的模型，在安全关键场景可能不可用。平均值会掩盖尾部风险。

Bessel 校正

总体方差：除以 N
样本方差：除以 (n−1) ← 用了样本均值，自由度少 1，避免低估方差

n 很小时差别明显；n 很大时可忽略。

2. 相关与协方差

Pearson

r = Σ(x−x̄)(y−ȳ) / (与标准差有关的分母) ∈ [-1, 1]

量线性相关；对异常值敏感。

Spearman

先变名次，再算 Pearson（或用名次差简式）。量单调关系；对异常更稳；y=x³ 时 Spearman 仍可接近 1。

协方差矩阵

  • 对角 = 各特征方差；非对角 = 两两协方差
  • 对称；编码线性共变结构
  • PCA 对其做特征分解；马氏距离用到 S⁻¹
  • 相关矩阵 = 标准化后的协方差矩阵

3. 假设检验与 p 值

H₀：默认（通常「无差别」）
H₁：你想支持的（「有差别」）
p = P(数据像现在这样或更极端 | H₀ 为真)
  • p 小（如 < 0.05）→ 拒绝 H₀，称统计显著
  • p 不小 → 不拒绝 H₀（≠ 证明 H₀ 为真）
  • p 不是「H₀ 为真的概率」

置信区间给出参数的合理范围；宽 = 不确定，窄 = 较精确（仍可能有偏）。

自由度 df

在已有约束下还剩多少独立信息。例如：用了样本均值再算方差 → df = n−1；卡方拟合比例 → df = 类别数−1。df 影响 t/χ² 分布形态与 p 值。

4. t 检验

类型 问题 要点
单样本 均值是否等于 μ₀？ t = (x̄−μ₀)/(s/√n)，df=n−1
双样本 Welch 两组独立均值是否不同？ 不假定等方差
配对 成对差值均值是否为 0？ ML 比两模型最常用：同一折上 dᵢ=Bᵢ−Aᵢ
配对：t = d̄ / (s_d / √n)

|t| 大 → 相对噪声的信号强 → p 小。|t| 与 p 是「尾部面积」关系，不是简单反比；正态近似下 |z|≈1.96→双侧 p≈0.05，|z|≈2.58→约 0.01。

5. 卡方检验（Chi-squared）

χ² = Σ (O − E)² / E
df = k − 1（拟合给定比例时）

比较观察频数与期望频数是否一致。χ² 大 → 卡方分布右尾小 → p 小 → 拒绝「一致」。适用于类别计数，不是连续均值。

6. A/B Testing for ML Models

A/B 是实验框架；t / 卡方 / 假设检验是决策工具。模型 A/B 常 = 同一数据配对 + 配对 t（或 Bootstrap CI）。
  1. 同一测试集 / 同一 k 折
  2. 多指标 + 估计方差
  3. 配对差值 → 检验 + 置信区间
  4. 效应量判断是否值得上线
  5. 最终 hold-out 防泄漏

7. 统计显著 vs 实际有用 · Cohen’s d

Cohen’s d = (均值差) / 标准差　（配对可用 d̄ / s_d）
|d|经验称呼
0.2小
0.5中
0.8大

为何 p 受样本量影响？

t ≈ √n × (差值 / 标准差) ≈ √n × d

n 变大 → 标准误变小 → 同样差别也更「显著」。故必须同时看 d：避免「显著但极小的提升」。

8. 多重比较问题

P(至少一次假阳性) ≈ 1 − (1−α)^m
m=20, α=0.05 → 约 64%

试得越多，越容易偶然显著。Bonferroni：α′ = α/m。也可用 FDR 等方法。超参搜索、多指标、多数据集时都要警惕。

9. Bootstrap（自助法）

  1. 有放回抽 n 个（有的点重复，有的缺失）
  2. 在自助样本上算指标
  3. 重复 B 次（如 1000～10000）
  4. 95% CI ≈ [2.5% 分位, 97.5% 分位]

几乎不挑指标、少分布假定。比较两模型：每次重采下标算 diff=B−A，看 CI 是否含 0。

0 的含义：两模型指标差为 0（一样好）。CI 含 0 → 仍可能没差别；不含 0 → 更支持存在真差别。

10. 参数 vs 非参数

参数 非参数
假定 常假定正态等 少假定形态
例子 t 检验、Pearson Spearman、Bootstrap、秩检验
何时 n 大、大致对称 偏态、异常、小 n、怪异指标

CV 只有 5～10 折时，有时 Wilcoxon 等比 t 更合适。

11. 中心极限定理（CLT）实用含义

样本均值 X̄ 在 n 大时 ≈ Normal(μ, σ²/n)
  • 支撑均值类指标的 CI 与 t 检验
  • 解释 CV 平均、mini-batch 梯度平均、集成平均为何更稳
  • 不让原始数据变正态；只作用于均值的抽样分布
  • 重尾无限方差或强依赖数据时不能直接套

12. 一句话速查

  • 描述 均值/中位数/分位数一起看，盯住尾部
  • Bessel 样本方差除以 n−1
  • Pearson 线性；Spearman 单调/秩
  • 协方差阵 PCA 与马氏距离的基础
  • p 值 H₀ 下数据极端程度，非 H₀ 为真概率
  • df 去掉约束后的独立信息量
  • 配对 t 同一折比两模型
  • 卡方 观察 vs 期望频数
  • A/B 框架；检验是工具
  • Cohen’s d 效应大小；p 随 n 变、d 不太随
  • 多重比较 多试抬高假阳性；Bonferroni
  • Bootstrap 重采样得任意指标 CI；差值 CI 是否含 0
  • CLT 均值变正态，不是数据本身
最终记住：点估计不够 → 加置信区间与检验；显著不够 → 加效应量；多试要校正；分布可疑或指标复杂就用 Bootstrap。统计是为了少把噪声当成进步。
