1. 核心概念速览

每个神经网络 = 矩阵乘法 + 额外步骤。
output = activation(weights @ input + bias) 这一行，就是一层网络的前向传播。

向量与矩阵

  • 向量：一串有序数字。在 AI 里代表数据点、特征、参数。
  • 矩阵：二维网格。m×n = m 行 n 列。
  • 把矩阵看成线性变换：它把一个空间的向量映射到另一个空间（旋转/缩放/投影）。

形状严格性（为什么出错）

(m × n) @ (n × p) = (m × p) 内维必须相等：n 必须等于 n 例：128×784 权重 @ 784×1 输入 = 128×1 输出

在 PyTorch/NumPy 里看到 shape mismatch 报错，就是内维不匹配导致的——这正是这一条规则在工作。

运算一览

运算作用神经网络用途
加法逐元素相加加 bias
标量乘法每一项乘以一个数学习率 × 梯度
矩阵乘法 @行 × 列 点点积一层的正向传播
转置 T行列互换反向传播
行列式 det一个数字概括判断是否可逆 / 面积缩放
逆矩阵撤销变换解线性方程组
单位矩阵 I什么都不变初始化、残差连接 (ResNet)

元素级乘法 * VS 矩阵乘法 @

这是新手最容易混的坑。下面是同一个 A、B 两种乘法的对比（运行结果）：

元素级乘法 *

| 1 2 | | 5 6 | | 5 12 | | 3 4 | * | 7 8 | = | 21 32 |

[i][j] 与 [i][j] 对位相乘。形状必须相同。

只是对位，不做混合 → 神经网络一般不直接用它做层变换。

矩阵乘法 @

| 1 2 | | 5 6 | | 19 22 | | 3 4 | @ | 7 8 | = | 43 50 |

第 [i][j] 个元素 = 第 1 矩阵第 i 行 与 第 2 矩阵第 j 列 的点积。内维相等。

让每个输出同时看到所有输入 → 神经网络的变换核心。

2. 关键术语

术语人们怎么说实际含义
向量「一个箭头」一串有序数字，高维空间里的一个点
矩阵「一张数字表」一个线性变换，把向量从一个空间映射到另一个
矩阵乘法「就是把数字乘一下」第一个矩阵的每一行与第二个矩阵每一列做点积。顺序很重要
转置「翻转」m×n → n×m。反向传播中至关重要
行列式「从矩阵算出的某个数」衡量矩阵把面积(2D)或体积(3D) 缩放了多少。0 = 变换压扁了一个维度
逆矩阵「把矩阵撤销」逆转变换的矩阵。只有 det ≠ 0 时才存在
单位矩阵 I「无聊的矩阵」等于「乘 1」。用于残差连接
广播「魔法修正形状」把较小的数组沿缺失维度重复扩展以匹配较大的
元素级「普通乘法」匹配位置相乘，形状需相同（或可广播）

3. 可视化 1 · 行列式 = 面积缩放（可逆性）

一个 2×2 矩阵 A = [v1 v2] 的列向量把「单位方格」（由 [1,0] 和 [0,1] 张成）变成一个平行四边形。

  • det(A) = 变换后面积 / 原面积
  • det = 0：两个列向量共线 → 平行四边形被压成一条线 → 维度被压扁 → 没有逆矩阵（信息丢失，无法逆转）。
  • det < 0：变换把空间「翻了个面」（镜像）。

这直接连接上一课的「秩不足 → 压扁维度」：det=0 就是 2×2 矩阵秩不足的数值表现。

6. 手写实现复盘（Build It）

用纯 Python 手写 Vector 和 Matrix 类，理解每一种运算的底层逻辑。

Vector 类

  • 加 / 减 / 标量乘
  • dot 点积 = sum(a*b for zip)
  • magnitude 长度 = 平方和开根
  • normalize 单位化

Matrix 类

  • 加 / 减 / 标量乘 / 元素级乘
  • matmul：三重循环，第 [i][j] = Σ a[i][k]·b[k][j]
  • transpose：行列互换
  • determinant：1×1、2×2 直接算，更大用展开
  • inverse_2x2：adjugate / det
  • identity / zeros / random

手写逆矩阵的公式（2×2）

A = | a b | A⁻¹ = 1/det · | d −b | | c d | | −c a | det = a·d − b·c

注意：只要 det = 0 就会 raise ValueError("Matrix is singular") —— 数学上就是「无法撤销」。

验证：A @ A⁻¹ = I。运行结果正是单位矩阵（对角线 1，其余 0）：

7. 用矩阵类搭两层神经网络

只用上面手写的 Matrix 类（不用 NumPy）跑通完整前向传播。形状流动：

输入 x (3,1) → W1@x (4,3)@(3,1) = (4,1)，加 bias b1 (4,1) → ReLU → h1 (4,1) → W2@h1 (2,4)@(4,1) = (2,1)，加 bias b2 (2,1) → 输出 z2 (2,1)

ReLU 就是逐元素取 max(0, v)。看运行结果里隐藏层 pre-activation 有几个负值，经过 ReLU 都变成了 0——这就是「激活函数引入非线性」的几何体现。

权重矩阵 = 一排检测器（连接「矩阵=模型」）

课程 demo 里有一个最直观的权重矩阵：

W = | 1 0 0 | ← 只复制特征 0 | 0 1 0 | ← 只复制特征 1 | 0.5 0.5 0 | ← 取特征 0 和 1 的平均

三个输出 = 三个「特征检测器」，每个都对输入做一次不同组合。训练神经网络，就是在学习这一排检测器该长什么样。

8. 建议练习

  1. 验证逆矩阵：用 3 个不同的 2×2 矩阵计算 A @ A.inverse_2x2()，确认都得单位矩阵。当 det=0 时发生了什么？
  2. 实现 3×3 逆矩阵：用伴随矩阵法扩展，和 np.linalg.inv 对比结果。
  3. 搭两层网络（只用 Matrix 类，不用 NumPy）：输入(3) → 隐藏(4) → 输出(2)。随机初始化权重，跑前向传播，验证所有形状正确。
  4. 用 NumPy 实现第五节广播：matrix + np.array([10,20,30])，理解它为何自动复制到每行。
手写是为了理解原理；真正工作用 NumPy：A@B、A.T、np.linalg.det、np.linalg.inv、np.eye(n)，并且 `@` 用 C/Fortran 写的 BLAS，快 100 倍。
