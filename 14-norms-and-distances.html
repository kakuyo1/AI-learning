14 Norms and Distances

高可视化复习 · 范数 · 距离 · 损失 · 正则 · 最近邻

距离函数 = 你定义的「什么叫相似」。选错了，KNN、检索、聚类、损失优化的目标都会偏。

1. 范数：向量有多「大」

距离常写成差的范数：d(a,b) = ||a − b||。

范数 公式直觉 单位球形状 一句话
L1 各维绝对差之和 菱形 曼哈顿：只能横竖走
L2 √平方和 圆形 直线距离
L∞ max|各维差| 正方形 只看差得最多的那一维
A=(1,1), B=(4,5)
L1 = 3+4 = 7  |  L2 = 5  |  L∞ = max(3,4) = 4

L1 要点

  • 对异常更稳健；适合稀疏高维
  • 正则 → Lasso：菱形角在轴上 → 权重易变 0 → 特征选择
  • 损失 → MAE

L∞ 要点

  • 最坏维说了算（国王走法、公差）
  • Lp 在 p→∞ 时的极限

2. Cosine Similarity / Distance

cos_sim = (a·b) / (|a||b|) ∈ [-1, 1]
cos_dist = 1 − cos_sim
只比方向、不比长短。文本与 embedding 检索首选。
  • 同向 → 1；垂直 → 0；反向 → −1
  • 向量已单位化时，点积 = cosine
  • 长度有意义（热度等）时可用点积；只要主题方向时用 Cosine

3. Mahalanobis Distance

d_M(x,y) = √[ (x−y)ᵀ S⁻¹ (x−y) ]　（S = 协方差）

先按数据的方差和相关性「摆正、缩放」，再量欧氏距离。等距线是椭圆而非圆。

  • 身高–体重相关时，能认出「又矮又重」更异常
  • 适合异常检测、特征相关且尺度不同时
  • S=I 时退化为欧氏距离

4. Jaccard Similarity（集合）

J = |A∩B| / |A∪B|

只看有没有，不看次数。标签、关键词集合、IoU 分割评估常用。

5. Edit Distance（Levenshtein）

字符串 A 变成 B，最少几次插入 / 删除 / 替换。

kitten → sitting = 3

拼写纠错、模糊匹配、去重；DP 表右下角即距离。

6. KL Divergence（不是距离）

D_KL(P||Q) = Σ P log(P/Q)
  • 用 Q 近似 P 的信息损失；一般不对称
  • Forward KL 偏 mean-seeking；Reverse KL 偏 mode-seeking
  • VAE、蒸馏、RLHF 里常见

7. Wasserstein（推土机距离）

把分布 P「搬成」Q 所需的最小功（土量×距离）。
  • 对称，是真度量
  • 分布几乎不重叠时仍有有限值（KL 易爆）→ WGAN 等用它
  • 1D：W₁ = ∫|CDF_P − CDF_Q| dx

8. 与损失函数的关系

损失函数 ≈ 选一种距离/散度 + 决定怎么惩罚。
损失 背后距离/散度 行为
MSE L2 平方 严惩大误差
MAE L1 线性惩罚，更稳健
Huber 小 L2、大 L1 稳健 + 近零光滑
Cross-entropy KL 对齐概率分布
Hinge 间隔 只罚间隔不够
Triplet / Contrastive 多为 L2 拉近正样本、推远负样本

交叉熵完整例子

三分类，真标签「猫」→ P=[1,0,0]；模型 Q=[0.7,0.2,0.1]

H(P,Q) = −log(0.7) ≈ 0.357
= 正确类的负对数概率
最小化交叉熵 ⇔ 最小化 KL(P||Q)（one-hot 时 H(P)=0）

正确类概率越接近 0，损失趋向 +∞ → 严厉惩罚「完全分错」。

9. 与正则化的关系

总目标 = 数据损失 + λ ×（权重范数）

为什么要惩罚权重大小？

  • 只拟合训练数据 → 权重易过大、过尖 → 过拟合
  • 正则偏好更小/更稀的权重 → 更平滑、通常更好泛化
  • λ 平衡「拟合」与「别太狂」
正则 形式 约束形状 效果
L1 Lasso λ||w||₁ 菱形 稀疏，权重可精确为 0
L2 Ridge λ||w||₂² 圆形 整体缩小，很少为 0
Elastic Net L1+L2 — 稀疏 + 稳定，相关特征成组
菱形角在轴上 → 等高线易碰角 → L1 稀疏；圆形无角 → L2 不稀疏。

10. Nearest Neighbor Search

按选定距离找最近的点。精确搜索 O(n·d)，大数据用 ANN：

  • KD-tree / Ball tree：空间划分
  • LSH：哈希分桶
  • HNSW：多层图（向量库常用）
  • IVF + 量化：先聚类再搜，可上十亿级

两层选择：① 哪种距离定义「像」；② 精确还是近似算法。

11. 一句话速查

  • L1 网格距离 · MAE · Lasso 稀疏
  • L2 直线距离 · MSE · Ridge 缩小
  • L∞ 只看最大维差
  • Cosine 只比方向 · 文本/embedding
  • Mahalanobis 协方差感知 · 异常检测
  • Jaccard 集合重叠
  • Edit 字符串改几次
  • KL 分布差（非对称）
  • Wasserstein 搬土最小功
  • 损失 距离 + 惩罚方式
  • 正则 惩罚权重大小防过拟合
  • ANN 近似最近邻加速检索
最终记住：范数量大小，距离量远近；损失与正则是同一种范数语言用在「误差」和「权重」上；检索则是在选定距离下找邻居。
