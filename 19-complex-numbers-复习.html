1. 复数是什么

实数是一条线。复数把数扩成平面：横轴实部、纵轴虚部。每个复数既是一个点，也是从原点出发的箭头。
z = a + bi　（i² = −1）
复平面：点 (3,2) = 3+2i
i 可理解为「转 90°」：乘一次 i 转四分之一圈；i²=−1 就是转半圈。

2. 四则运算与共轭

运算做法
加法实部加实部，虚部加虚部（向量相加）
乘法展开并用 i²=−1；极坐标下：长度乘、角度加
共轭a+bi → a−bi（关于实轴反射）
除法分子分母同乘分母的共轭
模长|z|=√(a²+b²)
(a+bi)(a−bi) = a²+b²　（模长的平方，为实数）

3. 极坐标与欧拉公式

同一个点可用「往东 a、往北 b」描述，也可用「距离 r、转角 θ」描述。后者对旋转更自然。
z = r (cosθ + i sinθ) = r · e^(iθ)
r = |z|，θ = atan2(b,a)
欧拉公式（本课核心）：
e^(iθ) = cosθ + i·sinθ
特别地：e^(iπ) = −1，故 e^(iπ)+1=0

θ 从 0 变到 2π，e^(iθ) 沿单位圆转一整圈。

4. 为什么乘法会旋转

极坐标下一眼能看清：两个复数相乘 = 半径相乘、角度相加。
z·w = |z|·|w| · e^(i(∠z+∠w))
  • |w|=1（单位圆上）→ 只旋转、不缩放
  • w = i = e^(iπ/2) → 逆时针转 90°
  • 与二维旋转矩阵是同一件事的两种写法
乘法的几何：转 + 缩放

5. 相量：旋转箭头代替正弦波

与其盯着扭动的正弦曲线，不如盯着匀速旋转的箭头。波形只是箭头在实轴上的影子。
信号语言相量语言
幅度 A箭头长度
相位 φ固定偏角
频率 ω旋转角速度
两信号相加两箭头矢量相加
e^(iωt) = cos(ωt) + i sin(ωt)
实部 = 余弦波，虚部 = 正弦波

6. 单位根与 DFT

把单位圆均分成 N 份，得到 N 个点——N 次单位根。它们是 DFT 的「标准频率」。
ωₖ = e^(2πi·k/N)　k=0,1,…,N−1
满足 (ωₖ)ᴺ = 1
和 e^(iπ) 的关系：所有 e^(iθ) 都在单位圆上。 e^(iπ)=−1 是半圈那个点；e^(2πi·k/N) 是一圈 N 等分后的第 k 个点。 N=2、k=1 时两者相同。
DFT:　X[k] = Σₙ x[n] · e^(−2πi·k·n/N)

每个 k 对应一种转速；DFT 测量信号与这些旋转有多同频。

7. 和 Transformer / RoPE 的关系

  • 正弦位置编码：sin/cos 对 = 不同频率复数指数的实部/虚部；低频粗定位、高频细定位
  • RoPE：对 query/key 做复数旋转，相对位置变成转角差，注意力自然带上相对位置信息
从几何到模型的一条线

8. 一句话速查

  • 复数 平面上的点/箭头；i = 转 90°
  • 欧拉 e^(iθ)=cosθ+i sinθ，单位圆
  • 乘法 角度加、长度乘；|w|=1 则纯旋转
  • 相量 旋转箭头；影子=正弦；相加=矢量加
  • 单位根 e^(2πi k/N)，圆上 N 等分；DFT 频率
  • RoPE 用旋转把位置写进 q/k
