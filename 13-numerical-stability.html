13 Numerical Stability

高可视化复习 · 浮点数 · 溢出下溢 · 稳定 Softmax · 混合精度 · 梯度裁剪 · 归一化

浮点数是漏水的抽象。训练中的 NaN、掉点、静默错误，很多最终都能追到数值问题。

1. IEEE 754：电脑如何存小数

值 = (-1)^sign × 2^(exponent - bias) × 1.mantissa
部分 作用 决定什么
Exponent 指数 小数点能移多远 范围（多大 / 多小）
Mantissa 尾数 有效数字有多少位 精度（能区分多细）

为什么 23 位尾数 ≈ 7～8 位十进制精度？

十进制位数 ≈ 二进制位数 × log10(2) ≈ 位数 × 0.301
float32 有效位约 24（含隐藏 1）：24 × 0.301 ≈ 7.2
格式 指数 尾数 范围 精度 训练
float32 8 23 大 ~7–8 位 稳但慢
float16 5 10 小（~65504） ~3–4 位 易溢出，需 loss scaling
bfloat16 8 7 大（同 float32） ~2–3 位 范围够，更省心
训练时范围往往比多几位精度更重要 → 更爱 bfloat16。

2. 溢出、下溢、灾难性消去

问题 含义 典型场景
Overflow 太大 → inf exp(100)、logits 过大
Underflow 太接近 0 → 0.0 小概率连乘、小梯度
灾难性消去 两相近大数相减，有效位抵消 方差 E[x²]-(E[x])²、过小 h 的差分

避免灾难性消去

  • 方差：先中心化再算 E[(x-μ)²]，或用 Welford 在线更新（始终基于相对均值的偏差）
  • Log 概率：全程在 log 空间（乘法→加法，加法用 log-sum-exp），不要先算出极小概率再 log
  • 总原则：改公式，消灭「大数减大数」和「中间结果极端大/小」

3. 稳定 Softmax 与 Log-Sum-Exp

先减 max，再 exp：最大项变 exp(0)=1，既不溢出，分母也不会下溢成 0。
softmax(x_i) = exp(x_i - m) / Σ exp(x_j - m)，其中 m = max(x)
log(sum(exp(x))) = m + log(sum(exp(x - m)))

交叉熵、序列 log 似然、混合高斯等处都会用到同一思想。

4. Numerical Gradient Checking

用中心差分估算梯度，和反向传播的解析梯度对比，检查实现是否写错。
∂f/∂x ≈ [f(x+h) - f(x-h)] / (2h)
  • h 一般取 1e-5～1e-7（太小会消去，太大约不准则）
  • 相对误差 < 1e-7：很好；> 1e-3：可能有 bug
  • 只在实现新层/新损失时用；可用 float64 更稳

5. Mixed Precision Training

前反向用低精度加速，主权重和关键计算保留 float32；float16 时配合 loss scaling 防梯度下溢。

典型流程：

  1. 维护 float32 主权重
  2. 前向用 float16/bfloat16
  3. loss 在 float32 算
  4. 反向低精度 → 梯度 scale 后转回 float32
  5. 用 float32 更新主权重

Loss scaling： loss 先乘大系数 S → 梯度放大避免下溢 → 更新前再除以 S。

bfloat16 vs float16： 前者指数 8 位、范围大，训练往往更省心。

6. Gradient Clipping

限制梯度大小，防止一步更新过大导致爆炸 / NaN。
方式 做法 特点
按值 clip 每个元素 clamp 到 [-m, m] 简单，可能改变方向
按范数 clip（常用） ‖g‖>max_norm 时整体缩放 保持方向不变
if ||grad|| > max_norm: grad *= max_norm / ||grad||

常见 max_norm：1.0（Transformer）、0.5（RL）等。

7. Normalization Layers as Numerical Stabilizers

BatchNorm / LayerNorm / RMSNorm 不只是加速收敛，更是把每层激活拉回安全数量级的数值稳定器。
LayerNorm(x) = (x - mean) / (std + ε) × γ + β
  • 减均值、除标准差 → 尺度回到约 1
  • ε 防止除零
  • γ、β 可学习，需要时仍可放大/平移

没有归一化时，激活可能随深度指数增长直到 overflow；有了之后，前向数值和反向梯度都更可控。

8. 一句话速查

  • Exponent 管范围；Mantissa 管精度
  • 24×0.301≈7.2 → float32 约 7～8 位十进制精度
  • 减 max Softmax / log-sum-exp 防溢出
  • 中心化 / Welford 稳定算方差
  • 全程 log 空间 避免概率下溢
  • 数值梯度检查 中心差分验解析梯度
  • 混合精度 低精度算 + float32 主权重 + loss scaling
  • 梯度裁剪 按范数缩放，保方向
  • Normalization 每层拉回安全尺度
最终记住：在有限精度下，通过改公式、减 max、缩放、裁剪和归一化，让训练既快又不会静默死在 NaN 里。
